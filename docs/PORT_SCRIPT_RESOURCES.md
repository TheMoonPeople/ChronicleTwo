# Native resource references in compiled scripts

The extractor migrates resource operands in retained SB2/STB bytecode after publishing the native assets. Resource paths must match the raw asset inventory and an actual published file. Character and model references name glTF, texture and general configuration references name JSON, sound references name `.sound.json`, and movies name self-contained MP4 files. Bare character profile selectors name a profile in the adjacent gameplay JSON document. A filename with whitespace immediately before its extension is corrected only when the original has no exact match and the corrected full path identifies an existing converted inventory asset; absent resources retain their original strings.

A complete validated VM script takes precedence over coincidental archive headers. An ordinary archive whose first member is named `SB2` or `STB` remains an archive. Publication verification checks every original VM against its exact deterministic migration, including scripts retained inside character resources.

The converter decodes the program table, reachable function calls, and valid unreferenced helper functions. It validates instruction bounds, function frames, jumps, calls, and terminated string operands. Replacement strings are appended to the file, and only the code-relative string offset of the corresponding `PUSH_CONST` instruction changes. Instruction locations, jump targets, call targets, program entries, numeric constants, CP932 dialogue, and unrelated strings retain their original bytes. Nested ordinary archives can grow script members without moving their other payloads or traversal headers. Repeating conversion makes no further changes.

Character profile arguments are identified from the actual profiles published with a character, including direct calls using dynamic character paths. The event commands `LOAD_CHARA` (9), `LOAD_MOTION` (19), `LOAD_ITEM` (30), and `LOAD_EQUIP` (511) account for every observed CFG string argument in the PAL corpus. Runtime file loading performs no legacy extension translation.

A pre-migration audit decoded 1,399 PAL scripts and 306,374 reachable string pushes. Resource operands included 24,074 CHR paths, 29,373 CFG profile selectors, 2,675 sound paths, 2,063 texture paths, 94 MDS paths, and 48 movie paths. The CFG arguments were consumed by command 9 (11,083), command 19 (10,188), command 30 (305), and command 511 (7,797); none were unclassified. Maintained tests cover append-only relocation, unchanged branches and CP932 text, dynamic profile arguments, unreferenced helpers, invalid jumps, and growing nested scripts beside untouched payloads.

The read-only resource audit recognizes complete VM headers independently of filename suffixes, including `mainchr/c02.stb_`. It covers 1,399 retained PAL scripts and reports resolvable legacy operands, missing direct targets, invalid programs, and original references whose source assets are absent from the disc separately.
