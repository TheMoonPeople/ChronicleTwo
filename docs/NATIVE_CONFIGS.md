# Native tagged configuration documents

configs.rs converts direct and PACK-contained CFG scripts to `.cfg.json` and MAP scripts to `.map.json` at the same physical path. Distinct family suffixes preserve scripts that share a retail stem with each other or with an IMG texture document. Conversion rejects any remaining output collision before overwriting an asset. PACK names remain directory components. Character profiles reside in character .game.json files; sound CFG/VOL files use the audio converter. IMG configuration belongs to the texture converter. No CFG catalog is published or used at runtime.

Tagged documents contain schema_version 1 and ordered commands. Text commands use command; BIN commands retain signed tag_index. Arguments use type and value: int is signed 32-bit, float retains single-precision rounding, string is readable UTF-8 decoded from CP932, and invalid preserves malformed or missing operands. game_bytes appears only when CP932 decoding and encoding cannot reproduce the original text bytes, including duplicate vendor mappings. Entire source scripts are not retained.

The existing interpreter defines comment removal, including markers inside quotes, ASCII whitespace, Shift-JIS lead bytes and escaped quotes. Numeric prefixes and invalid tokens preserve native behavior. An incomplete final argument without its delimiter is omitted. Unknown names remain available for the active tag table to skip. BIN records preserve aligned values and termination, including zero-index commands with no arguments.

Only known resource-bearing command argument positions receive native filename migration, and their identities must resolve against the extracted inventory. These include character/model/image/motion fields, sky and map-part model names, and movies. Gameplay names and arbitrary text remain unchanged. CHARA profile arguments become semantic profile names. Character profiles use typed integer resource references.

All 210 PAL MAP files are tagged text scripts. Their IMG operand is argument zero and their PIECE operand selects the exact native model filename. PCP operands retain the actual archive-directory name. The numeric map table's PIECE entry is index 43; BIN scripts preserve that index while migrating its model argument. The scene loader handles IMG/PCP declarations before the map interpreter executes placement commands.

The five menu/1..5/help.cfg files use the caption consumer. Their kind movie_subtitles documents contain chapters with id and ordered entries. Entries have double-precision start_seconds, clear_seconds and text. Native timing converts seconds into frames. Timing-only final slots remain empty captions. Text follows MyStrCpyLineFeed, including literal backslash-n conversion and carriage-return preservation. Unknown lines follow the native consumer's skip rules.

Direct CFG/MAP scripts and converted PACK members disappear. Ordinary PACK containers become physical asset directories; only surviving member payloads are copied. configs::verify walks typed documents and rejects retained CFG/MAP payloads. Native code executes typed JSON directly without rebuilding text or BIN data.

tools/kazarov/scripts/cfg_parity_fixture.py prepares a private test manifest of original paths and actual native JSON paths, or character glTF/sidecar/profile references. This fixture is not a runtime catalog. Parity compares adapters against original consumers and accounts explicitly for migrated resource operands. Character texture bindings use `--texture-oracle <private-port_data>` from an original IMG/TIM2 texture conversion. The test compares the complete texture document and decoded RGBA pixels for every mip and variant; preserved historical PNG filenames do not determine ownership. It parses only standard glTF scenes and images and retains one character bundle at a time. PAL contains 4,679 tagged CFG files and five caption files before character profiles move into character sidecars.
