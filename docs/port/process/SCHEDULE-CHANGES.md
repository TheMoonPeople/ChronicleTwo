# SCHEDULE.md revision 2 (12 Oct, after W2.c): what changed and what to do now

## What changed

1. **`uptr` replaces widening copies** (hard rule 12, section 1). `ps2/include/types.h` gets `uptr`/`sptr` (`unsigned int`/`int` on the PS2; `__UINTPTR_TYPE__`/`__INTPTR_TYPE__` under `#ifdef PORT`). Every pointer-to-int cast, address-holding local/global/non-record field and address-returning return type in `ps2/src` becomes `uptr`; `sptr` only where MWCC codegen is signedness-sensitive (signed compare, `>>`, `/`, `%`, float conversion, widening into 64-bit `long`, signed fields so used). Both are byte-identical on the PS2; `verify.py -c` after every batch of 6 units proves it. **Parameter types never change** (mangled): such functions become override pairs owned by their unit's stream. Hand-written strides (`(i << 2) + (uptr) this + offsetof`) are rewritten to indexing only where byte-identical, else kept as port "stride fixes" (not widenings). New stream **`uptr`** (W2, starts now) owns `ps2/**` exclusively, `truncations.py`/`.md`, the records inventory, `docs/PC.md` "Pointers and 32-bit integers", and the deletion of `mg_texture.cpp`'s widening-only overrides (SetTableBuffer/Initialize/SearchHash; mg_tanime's goes to draw2d by NEEDS). While it runs, **no other stream edits `ps2/`** (NEEDS instead). Checkpoint **W2.u** merges it as soon as accepted (independent of W2 end); running streams then rebase. Acceptance: ps2-pal byte-identical; Linux+Windows green; `truncations.py --check` = 0 open round trips in linked code and 0 narrowing casts in compiled `ps2/` code (or each listed with its owner); `uptr_test` round-trips an address above 4 GiB; a `Truncations.Check` ctest case.
2. **Records** (hard rule 13; stream **`records`**, W3, after W2.u): structs read from the disc in place keep their 32-bit layout, never hold pointers, get `PORT_RECORD_ASSERT(sizeof)` (a `static_assert` on PC), and are resolved on access or decoded into host tables. Per-format table in section 5 (DATA.HD4/PACK done by `data`; MDT/MOT on-access by `prog0`; IMG/TM2 done; sound by `audio-game`; script stack side table, villager tables, edit/effect decoders by `records`; movie replaced whole). `records.py` checks the inventory in CI.
