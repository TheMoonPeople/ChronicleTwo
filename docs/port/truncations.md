# Pointer truncations

Generated by scripts/port/truncations.py from the native compile database and linked game.
Regenerate after changing native source or compiler flags.

The report audits port/src and port/include code in the native target. A round trip narrows an address and later uses it as a pointer. An escape stores a narrowed address where the analysis cannot follow its reader. Low-bit casts use only a mask, residue, or other bounded part of the address.
