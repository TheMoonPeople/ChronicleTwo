# Motion names

Every original motion name the CFG profiles use — KEY intervals, sequence names (`SEQ_START`, `SEQ`) and the
motions sound cues name (`SE`, `SELP`) — has one English name in
`tools/kazarov/assets/motion_names.json`. The exporter names each glTF animation (a Blender action) and every
profile reference with it, and conversion fails when a name is missing from the table. Names are lower
`snake_case`. Each bundle's `game_names` maps its English names back to the originals, which the game compares
byte for byte.

Conventions: `L`, `Ｌ` and `ループ` (a held or looping pose) become `_loop`; `in` and `out` stay `_in` and
`_out`; `入り` (entering a pose) becomes `_enter` and `戻り` (returning from it) `_return`; `右`, `左`, `前`
and `後` become `right`, `left`, `front` and `back`. Full-width and ASCII digits translate alike. Character
names follow the file stems: ミンツ and ユリス are Max (`max`), モニカ is Monica, ギルトーニ is `guiltoni`,
ポルカス is `polcurse`, and others keep their romanized names (`eina`, `shigu`, `shirooza`, `paw`, `baru`, `oz`).
Retail `_s` suffixes are kept. Different originals that translate alike in one bundle take `_v2`, `_v3`
suffixes in that bundle (for example `歩き2` and `歩き２`).

Uncertain translations, where the original is a sound effect, a staging cue or a numbered cut: `！！` (`exclaim`),
`G`/`Ｇ` (`g`), `1`–`5` (`pose_1`–`pose_5`), `26＿27`, `29`–`35`, `34_2`, `35_L` (`cut_*`), `3ren`/`4ren`/`5ren`
(`triple_combo`/`quad_combo`/`quint_combo`), `ｴﾌｪｸﾄ_ﾃﾞｽｱｰｸ煙` (`effect_death_arc_smoke`), `テレピート中`
(`teleporting`, read as a misspelt テレポート), `時の～専用上～見立ちに` (`time_only_look_up_to_idle`),
`あいつは～専用` (`that_guy_only`), `原点` (`origin`), `配合` (`blend_combine`), `立ちN` (`idle_n`) and the
onomatopoeia (`パオーン` `trumpet`, `ウッキー` `ook_ook`, `ぶしゅー` `pssh`, `ゴゴゴゴ` `rumble`).
