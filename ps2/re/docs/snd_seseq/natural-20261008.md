## Kept

- `sndCSeSeqData::LoadSMF`: `cursor = (char *) (header_size + (int) smf + 8)`
  skips the SMF header chunk. Retail adds `smf` to the header size
  (`addu v1,v1,s0`); every pointer form (`smf + header_size + 8`,
  `header_size + smf + 8`, `&smf[header_size + 8]`) puts the pointer
  operand first.
- `BigToLittle` reverses bytes between raw buffers.
