# CollisionFish lane loop

`CollisionFish__FP15RACE_FISH_PARAMi` is a static function. Its final lane
traversal assigns the lane counter, row base and inner byte induction to
`t3/t2/a3`; the variable sharing that produces this allocation is recorded in
[notes.md](notes.md).

The lane loop has no call consuming its binary32 0.05f (`0x3d4ccccd`)
separation distance, so no floating-argument selector applies to it. The
established public types are not narrowed: unsigned or halfword order/bucket
elements, counters and sorting temporaries add extension and induction
differences, and an unsigned inner comparison adds `sltu`. Scoped
`optimization_level 4` or explicit global optimization leaves the function
unchanged; level 2 or global optimization off produces a much smaller body.
