# menudraw: natural typed access (2026-10-08)

## Replaced

- `CMenuPosDataForm::Initialize`: every byte-offset store through
  `u8 *bytes = (u8 *) this` is a named field: `next_x`/`next_y` (0x24/0x28),
  `mtype = MENUFORM_MTYPE_N` (0x20), `rgba_bit` (0x50), the `rgba_add`,
  `rgba` and `rgba_target` channel arrays (0x51/0x55/0x59), `counter` (0x18),
  `chara` (0x38), `chara_tex_block`/`unk_36` (0x34/0x36),
  `action_no`/`action_state` (0x5E/0x60) and `sub_no` (0x1C).
- `MenuPosDataTypeInit`: `part->tex = NULL` instead of `*(int *) &part->tex = 0`.
- `CMenuPosDataForm::SetRGBACalcParam`: `rgba_add[index]` and
  `rgba_target[index]`.
- `CMenuPosDataForm::GetEnableEnterPart`: `for` loop over `parts[i]`.
- `CMenuPosDataForm::MenuFormStep`: the colour fade loop indexes `rgba_add`,
  `rgba` and `rgba_target`; the step is read once into an `s8 step`.
- `CheckItemBoardFunc_MenuIconDrawPrepare` and
  `MenuItemBrdItemIconEffectMalloc`: `for` loops over `parts[i]`.
- `CRepairManager::LoadDataBG`: `(unsigned int *) &memory->stack[memory->stack_used]`.
- `InitInitBuildUpInfoEffectPos` and `DrawBuildUpInfoEffect`:
  `MenuVerticalLine[i]`.
- `CMenuEffect::SetTexInfo`: `tex_block = params[0]` instead of
  `*(short *) params`; MWCC loads only the low half for the `s16` store.
- `CLevelUpEffect::Generate`: `chara` is already `CCharacter2 *`; the same-type cast on the
  `GetPosition` call is dropped.
- `NowUseNeedItemCheck`: the ridepod weapon check calls `parts[0].GetWHp` directly instead of
  through `(CGameDataUsed *) &...->parts[0]`.
- `MenuVerticalLineChara` is a `CCharacter2 *`; `SetBuildUpInfoChara` compares and stores
  `chara` without `(int)`.
- `NowUseNeedItemCheck`: `GetUsedDataPtr` already returns `CGameDataUsed *`.
- `CheckItemUseVariable`: the item target is read through the `CItemUseTarget` union's `item` member
  instead of `(CGameDataUsed *) target.data`.
- `GetMenuMainIconChar` returns `char *` (menudraw.hpp), the `temp_3925` name buffer it
  formats; `CMenuPosDataManage::StepMainMenuIconMove` passes it to `GetFormInfo` without
  `(char *)`.
- `AttachMessageForm`: `GetFormInfo` already returns `CMenuPosDataForm *`.
- `DrawMenuDl`: the gaiji texture is an `mgCTexture *` and its `block` is passed,
  instead of reading the first `short` through a `(short *)` view.
- `Func_MenuIconDrawPrepare`: `item_info` is the `CDataItem *` that `GetItemInfoData` returns and
  the flag word is `item_info->use_flags` instead of `((unsigned int *) item_info)[1]`.
- `CRepairEffect::Generate` (`REPAIR_EFFECT_PARTICLE[particle_num]`) and
  `CRepairManager::Generate` (`CRepairEffect`) use placement `new` expressions instead of cast
  `operator new` calls.

## Kept

- `CRepairManager::SetStack`: `*(int *) &memory->stack` for `base` and the
  mode-1 `top`. Reading the pointer as a value (`(int) memory->stack`) changes
  the order of the `subu`/`sll`/`addu` that form the stack end.
  The mode-0 model stack keeps `(u8 *) top - 0x18000`; the integer subtraction
  `top - 0x18000` builds the out-of-range constant differently and adds an instruction.
- `CRepairManager::Generate`: `(u8 *) (slot * 0x30) + (int) this` then
  `+ 0x24`. `&effect_stack[slot]` matches except for the operand order of
  the `addu` (retail adds `this` to the scaled slot).
- `CLevelUpEffect::Step`: byte `offset` walk over `l_levelup_pos` and
  `l_levelup_vec`. `l_levelup_pos[i]` element pointers rotate the offset,
  counter and generate-counter registers; indexing at every use changes the
  instruction count.
- `CMenuPosDataManage::MallocPallet` and `SearchTransPalletNo`: `(u8 *)` views
  of the `u_long128` CLUT buffers read and write raw RGBA texel bytes.
- `NowUseNeedItemCheck`: the same-type `(ROBO_DATA *) &manager->robo_data` stays. Retail forms
  `&robo_data` (`addiu v0,s5,18016`) and then `parts[0]` (`addiu a0,v0,48`); without the cast MWCC
  folds both into `addiu a0,s5,18064`.
- `InitBuildUpInfoEffect`: `(CEffVerticalLine *) operator new[](size, ...)`. A
  `new (...) CEffVerticalLine[num]` expression keeps `num` in `s0` and shifts it again for the
  call instead of keeping `size`, one instruction longer.
