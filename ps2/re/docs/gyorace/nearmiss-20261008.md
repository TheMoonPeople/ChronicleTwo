# Fish-race display window data

Two retail-local globals supply the display's texture state:

| Symbol | Retail address | Size | Type and purpose |
|---|---:|---:|---|
| wind_tex | 0x0037E7D8 | 4 | mgCTexture pointer to the window/time-digit atlas |
| WindowTexb | 0x0037E820 | 4 | int texture block containing that atlas |

Both are unconditional static definitions in gyorace.cpp; both retail bindings are LOCAL.
`sgInitGyoRace` assigns them and `sgSysDrawGyoRace` reads them.

The display's five time digits are whole minutes, seconds tens/units and hundredths
tens/units. `lap_inf[2][5]` and `lap_inf2[5]` are persistent function-local state with retail
symbol sizes 0x28 and 0x14; the larger BSS extents after them are following storage and
alignment, not part of the arrays.
