# gyorace: natural typed access (2026-10-08)

No source change.

## Kept

- `sgInitGyoRace`: the loaded `u_long128` file buffers are passed to `sndLoadSound`, `LoadChara`
  (`unsigned int *` packs) and `EnterIMGFile` (`unsigned char *` images) through casts; the
  parameter types are part of those functions' mangled names.
- `DivSpriteScreen`: `uv = *(RaceVector *) origin` is a quadword copy of the `int origin[4]`
  vector. The array's initialiser loads a constant quadword template before patching in the
  screen offsets; a `RaceVector` local filled field by field stores the offsets directly and
  reorders the function's opening.
