## Allocator diagnosis

An LLDB capture of the 960-node GPR interference graph, with the Satan's
Fiddle hooks applied, reproduces the previous ten-word swap. Simulating
simplify, spill choice and colouring reproduces every captured colour.

Spill choice (`0x4AEED5`): when no node has degree below `K`, the remaining
nodes, in reverse scan order, are compared by `cost / current degree`, where
cost is the signed word at node `+0x0C`. Flag `0x80` gives `FLT_MAX` and flag
`0x400` gives `FLT_MAX / 2`. A strictly smaller value wins and the node is
pushed. Simplify then resumes.

In the guarded draft only six nodes stay at degree 25. The spill pick is v60
(degree 195, cost 3). The other five become pushable at degree 24 and are
pushed in vreg order: lap counter v36, row-offset induction v41, the two
coordinate inductions v43 and v44, and the row pointer v46. Popping colours v46
first (`s0`) and v36 last (`s4`). Retail's allocation needs the counter
numbered above v44 and the row pointer below v41. No single renumbering does
it.

The draft's counter reused `var_16` (a split web, numbered low) and `lap` was a
fresh pointer (numbered high), the reverse of retail. In retail the counter is a
fresh local and the row address is a load CSE temporary: the loop indexes
`lap_inf[lap_no][n]` directly, with no pointer variable.

### Mechanisms

- **Hero time pointer.** One `float *total`, declared before the
  goal test and assigned `&state->time` in each branch, is not
  forward-substituted. It has two definitions.
  - Normal branch: the running time is stored and read back through
    the pointer. This reproduces retail's store to `32(s3)` and reload
    (`+0x700..+0x764`). Direct `state->time` reuses the multiplied
    register.
  - Goal branch: the total is stored directly and the pointer is
    assigned afterwards. The address therefore follows the `RaceInfo`
    base and `20.0f` in emission order, which reproduces retail's
    `v1`/`v0` pair and its `s7` total pointer.
  - A single-definition pointer is propagated: the goal store would
    precede the pointer, or the pointer would fold into `32(s3)` and
    the `s7` reload would disappear.
- **Goal-branch constants.** The pre-RA list scheduler always runs in
  pressure mode. `0x498D98` sets the flag when a function's allocation
  starts and `0x4AF53C` clears it. The selector at `0x4AEA70` takes the
  first ready, issuable node in emission order. It replaces that node
  only with a later node whose pressure score is strictly lower.
  - The score at `0x4AE040` is 16, minus one for each register use that
    dies, plus one for each definition with remaining uses. Each term is
    weighted by max(live − limit, 1), which is 1 everywhere here. Kills
    of the dedicated result register `v0` are not counted.
  - `mtc1 v0` and a constant `lui` therefore both score 17, and emission
    order decides between them.
  - In `3600.0f * (float) (int) (time / 3600.0f)` the call subtree is
    heavier, so the conversion's `mtc1 v0` is emitted first and wins. Each
    constant then reuses `v0` after the conversion, which costs three
    instructions in each of the first two post-call blocks.
  - A reused `int count` ends each conversion in its own statement. The
    following `3600.0f * count` emits the constant first. Trace run 82
    shows the list as `[lui, mtc1 v0, lui]`. Both constants are scheduled
    before the `mtc1`, interfere with `v0` and take retail's `a2`/`v1`.
  - All three post-call blocks are then byte-exact. A single-definition
    `int` local is forward-substituted into the expression and changes
    nothing.
- **Fish-loop saved registers.** Reading the character number as
  `fish_inf[fish].chara_no`, rather than through `state`, gives retail's
  assignment: fish in `s1`, character in `s2` and the goal-time
  induction offset in `s4`. This removes every register-only difference.
- **Heading interpolation.** As its own statement, `float angle =
  atan2f(...)` emits `atan2f`'s second argument first. The first argument
  goes in the delay slot, and `0.034906585f` is materialised before
  `rotation[1]` is reloaded, all as in retail. The nested call reverses
  both orders.
- **String arguments.** The motion names, part/frame names and format
  strings are retail string literals, kept as `INCLUDE_RODATA` symbols.
  - Declared `char[]` and passed uncast, they are simple address
    arguments and are evaluated after the computed ones, as retail's
    literals are.
  - At `printf`, the computed rank and name address therefore come first,
    and the format's low half fills the delay slot.
  - At both splash `SetMotion` calls, the receiver copy now precedes the
    motion name's low half.
  - The previous `(char *)` casts of `const unsigned char` arrays made
    each name a computed argument evaluated in source order.
- **Splash gravity.** Retail materialises the non-battle `-0.1f` into
  `$f20` before the `mgDistVector`/`fptosi` calls, then moves it to
  `$f15`. Literal, `double`, local, two-branch-local and negated-local
  forms are all folded or propagated, or leave an unfolded `neg.s`. The
  proposed row selects the value as an evaluate-first `SethitEffect`
  argument.

renumbers the compiler-generated locals. Those numbers name the `at_NNN`
