# gyorace / gyoracesim hygiene pass (2026-10-09)

Checked with a PAL build (`SCES_511.90: OK`) and `check_objects.py` (149/149).

## Changed (`sgInitGyoRace`)
- `image->kind = HIT_EFFECT_BOARD` (`CHitEffectImage::kind` holds a
  `HIT_EFFECT_KIND`; 0 is the board kind).
- `SetActive(SCENE_DATA_CHARA, ...)` / `ResetActive(SCENE_DATA_CHARA, 0)`:
  `CScene::GetData` maps kind 1 to `GetSceneCharacter`.
- `LanguageCode > LANG_JAPANESE` for the localized atlas name.

## Nothing to do
- `sgSysDrawGyoRace`: `(sceVif1Packet *) NULL` selects the `ReloadTexture`
  overload, `(int) fish_inf[...].lap` is a required unsigned-to-signed
  conversion, race states and modes are already named.
- gyoracesim `CollisionFish`, `StepGyoRace`: the literals are lane/fish
  counts, the 16.0f course length and the 0.05f spacing; `(float) step` is a
  conversion. No `unk_` accesses.

## Left as is
- `GYORACE_FISH_INF::unk_14` is written 0 here and set to 1 when the fish
  starts its second lap (with `lap_start`) in guarded `sgLoopGyoRace`; nothing
  reads it. `second_lap` would fit, but one user is inside the
  `#ifdef NONMATCHING` block, so it is not renamed.
- `AssignStack(5)`/`GetStack(5)`, `sndSeAllStop(2)`: no enumerator. The same
  `HIT_EFFECT_BOARD`/`SCENE_DATA_CHARA` values in guarded `sgLoopGyoRace` stay.
