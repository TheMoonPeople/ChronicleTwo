# Natural effect-manager initialization residual

`_ESM_INITIALIZE` stays guarded. Its smallest measured natural pn15 source
differs by two words at +0xe8/+0xf0 in the exact 0x128-byte body, within a
0x130 layout extent. The inherited `Ident` helper gives a diagnostic zero
under the conversion but is inadmissible. Removing it without changing the
range calculation leaves nine register-operand differences.

The natural lead loads the real texture-block start and remaining count,
then adds the decoded offset to that start before calling manager Initialize.
It preserves the allocation size, constructor operations, global reloads,
signed arithmetic and documented argument decoding. Exact before and after
constructor timings produce the same two-word residual, with one witnessed
class-6 constructor. No dummy value, helper, alias or handwritten special
member is introduced.

Read-only backend observations are calibrated against genuine row-absent
compiler bodies and named relocations. Both inherited and natural sources
select 69 GPR virtuals. The natural start update permits an additional copy
merge, joining the base load and sum to the ABI argument a2 before register
coloring. Retail instead loads the base into v1 and adds it into a2. The
direct helper-free expression has 68 virtuals and a different saved-register
permutation; virtual count alone therefore does not explain the result.
These traces observe ordinary compilation and establish no new compiler
policy or activated-policy trace claim.

Twenty-three resumed source/profile controls preserve all 837 nonselected
native function payloads and named relocations, nonselected scores, compiler
diagnostics and float-policy traces. Final controls retain the full 27-row
production profile and reproduce their earlier complete native objects.
Remaining-count arguments, real start updates, reciprocal count transitions
and relative-index seeds find no natural zero. Previously documented spelling
negatives are not repeated.

Existing owner documentation and fresh m2c establish the manager, memory,
scene and sprite dependencies. Two comment-only shared-header proposals
separate actual symbol bodies from padded extents: manager Initialize is
0x128 within 0x130; the sprite constructor is 0x58 within 0x60. The headers
are untouched. No ESM profile row is committed while the caller stays guarded.
