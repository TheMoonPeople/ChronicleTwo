# event_func natural access (2026-10-08 night)

Byte-identical object (`check_objects event_func`: 0x22C74 bytes, 6920 relocations).

## Replaced
- `_GET_NEAR_TBOX_POS`: `(RS_STACKDATA *) ((int) stack + 0x18)` is `stack += 3`
  (`RS_STACKDATA` is 8 bytes). The manager is a `CTreasureBoxManager *` and each box is
  `&box_manager->box[i]` for `i < TREASURE_BOX_MAX`, instead of `u8 *` offsets
  `i * 0x70 + 0x10`.
- `_GET_EVENT_DATA`, case 8: the `(float *) &event_data->vectors_b.v[0]` / `vectors_a.v[3]` views
  are `event_data->map_event.matrix[3][0..2]` (the point's translation) and `matrix[2][0]`,
  `matrix[2][2]` (its z axis, for the yaw).
- `_GET_INVENTION_ID`: `(u8 *) &save->user_data + invent_user_data_offset` is
  `&save->user_data.invent_data` (0x7F30); the `invent_user_data_offset` constant is gone.
- 33 redundant `(CScene *) EventScene` casts (`EventScene` is a `CScene *`).
- `GetConfigCaptionOff`: reads `config->caption_off` without the `(s8)`
  conversion now that `SV_CONFIG_OPTION::caption_off` is `s8` (mapselect).
- `_MES_MAKE`: the message text is stored in `ClsMes::text_ptr` and passed to `MakeMesWin`
  directly; `text_ptr` is now `char *` (nd_meswin.hpp) instead of an `s32` written with
  `(s32) text` and read back with `(char *)`. Every other user only clears it.
- Frame handle scale: `handle->frame` (`mgCFrame *`) calls the inherited virtual `SetScale`
  without the `(mgCObject *)` upcast.
- `CEditParts *parts` calls the inherited `CMapParts::SearchPiece` without an upcast.
- `_SET_CAMERA_CTRL`: `camera` is a `CCameraControl *`, so `ControlOn`/`ControlOff` need no
  downcast; `FollowOn`/`FollowOff` are inherited from `mgCCameraFollow`.
- `_NORMAL_VECTOR`, `_ANGLE_LIMIT` and `_GOTO_USE_ITEM2` read referenced stack slots through
  `val.p` instead of `(RS_STACKDATA *) val.i`; `_GOTO_USE_ITEM` and `_GOTO_USE_ITEM2` compare
  `type` with `RS_PTR` rather than 3.
- GeoStone handle: `&GeoStone` is passed as the `CCharacter2 *` without a cast; `CGeoStone`
  derives from `CCharacter2` (dng_event.hpp, included).
- Object handle opcodes: the `mgCObject *` locals take `CEoh::object` (`CObject *`) without
  the `(mgCObject *)` upcast (14 sites).
- Shadow handle: `chara->shadow_frame` is already `mgCFrame *`.
- Player search: `SearchChara` returns `CActionChara *`, passed to the handle's `CCharacter2 *`
  without a cast.
- Monochrome flash: `mgTexManager.EnterTexture` already returns `mgCTexture *`.
- Same-type casts dropped: `mgCMemory *` stacks (`EventScene->GetStack(...)` results and
  `EventEffectScript->work_memory`, 16 opcodes),
  `EventScene` itself (`CScene *`), `GetCamera` results in `EdEventFinish`/`_CAMERA_STEP`, and
  `PakuMotionName`/`PakuMotionName2` in `_SET_PAKU_MOTION`.
- `_EOH_SYNC_EDIT_OBJ` passes the edit parts as `CObject *` without the upcast.
- `Hit_para` is `BattleEffectPrim[5][0x40]` (event_func.hpp), the spark type that
  `HitEffect[n].spark` points at; the duplicate `HIT_EFFECT_PARTICLE` struct is removed and the
  15 `(BattleEffectPrim *) Hit_para[n]` casts are dropped.
- `_SWE_INIT`: `chara->sword_effect[slot] = new (scene_stack->Alloc(12)) CSWordAfterEffect` uses the
  inline constructor for the two colours instead of a cast `operator new(0xA0, ...)` and repeating
  its stores.

## Kept
- `_DIST_VECTOR`, `_DIST_VECTOR2`, `_AMG_GET_ATTR_STATUS`: `stack = (RS_STACKDATA *) ((int) stack
  + 0x18/0x30)` before `SetStack(stack, ...)`. Retail keeps the advanced pointer in `s0` and adds
  in the delay slot of the preceding call; `stack += 3`, `stack = &stack[3]` and
  `SetStack(stack += 3, ...)` fold the add into the argument (`addiu a0,s0,24`).
- `_OBJS_SET_EOH_FRAME_POS`: `(u8 *) stack + vector_bytes` (`const int vector_bytes = 0x18`);
  `stack += 3` changes the function size.
- `_DELETE_CHARA`: `(CEoh *) ((u8 *) &EventObjHandleMother + offset)`. Both a
  `&EventObjHandleMother.eoh[i]` local and direct indexing rotate `a3`/`t0`/`t1` between the
  offset, the element and the `charaSlot` pointer.
- `_FUNCTION_MAP_JUMP`: `(char *) (request + 6)` from `&EventScene->map_jump_flags`.
  `EventScene->map_jump_name` (the same address) reloads `EventScene` and shrinks the function.
- `_SWE_SET_COLOR`, `_SWE_SET_TEXTURE`, `_SWE_START_EFFECT`: `(slot << 2) + (int) chara +
  chara_sword_after_offset` (0x570, `CCharacter2::sword_effect`). `&chara->sword_effect[slot]`
  and `chara->sword_effect + slot` give `addu v0,v0,v1` where retail adds the scaled slot first.
- Object handle drives: `((CCharacter2 *) *held)` converts the handle's `CObject *` to the
  character it holds; that is a base-to-derived downcast, not a pun.
- `_OBJS_SET_EOH_FRAME_POS`, `_DIST_VECTOR`, `_DIST_VECTOR2`, `_AMG_GET_ATTR_STATUS`: the
  stack advance past a vector stays an integer byte add (`(int) stack + 0x18`/`0x30`, or the
  `vector_bytes` constant). Retail updates the saved register (`addiu s0,s0,24; move a0,s0`);
  `stack += 3` folds into the argument (`addiu a0,s0,24`) and drops an instruction.
- `(CCharacter2 *) handle->object` locals convert the handle's `CObject *` down to the
  character; base-to-derived downcasts.
- `_SWE_*` opcodes: `(CSWordAfterEffect **) ((slot << 2) + (int) chara + chara_sword_after_offset)`
  keeps retail's index-first sum; `&chara->sword_effect[slot]` adds the base first (three sites
  differ).
- `_ESM_INIT_FIX`: `(mgCMemory *) operator new(0x30, ...)` then `Init()`. `new (...) mgCMemory`
  is one instruction longer (the null test moves after the copy of the result).
- Loaded data at API boundaries: `CheckLoadedBGFile` returns the `u_long128` read buffer as a
  `u32 *` pack, `GetLoadBGBuff` results are viewed as `MDS_HEADER *`, `char *` or `u_char *` by
  their users, and `CScreenEffect::CaptureSepiaScreen`/`CaptureMonoFlashScreen` walk
  `texture->image[0]` as RGBA bytes.
