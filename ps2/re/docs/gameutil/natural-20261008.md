# gameutil natural access (2026-10-08 night)

## Replaced
- `MotionProc3`: the vertex and normal overflow checks read
  `frame_info[list->frame]` instead of
  `(tagFRAME_INF *) ((list->frame << 5) + (int) frame_info)`.
- `mgCVisualMDT::face_group` is already `mgFACE_GROUP *`; both face walks drop the same-type cast.
- `tagFRAME_INF::vertex_refs` is a `FrameLinkRecord *` (moved from gameutil.cpp to gameutil.hpp,
  0x30 bytes). The link builders in `ChangeWeight` and `AnimeDataInit` take
  `&vertex_refs[from]` and clear `vertex_refs[i].count` instead of viewing an `int[12]` row.
- The memcpy sources `src_vertices`/`src_normals` (was `src_uvs`) are the visual's
  `sceVu0FVECTOR *` vertex and normal arrays instead of `int *` views.

## Kept
- `AnimeDataInit`: the parent field retains the signed integer-address quotient
  `((int) parent - (int) frame) / (int) sizeof(mgCFrame)` (the frame size is 0x110).
  Non-null MDS parents are elements of the same allocated frame array, but root
  parents are NULL and the initialization loop includes those roots. C++ array-pointer
  subtraction is undefined for that case. Retail computes the signed address quotient
  even for NULL; the current source does not read the resulting parent field. No new
  sentinel or root branch is introduced. The complete gameutil object remains exact
  at 0x5BCC checked bytes and 357 relocations.
- `GetFootPoly`: `int attribute_value[4]` written and read only through
  `*(float *) &attribute_value[3]`. Declaring it `float attribute_value[4]` lets MWCC keep
  element 3 in `$f21` (the frame shrinks by 16 bytes and `$f21` is saved), where retail keeps it
  in the stack array.
- `ChangeWeight`: `data` is a serialized stream of 32-byte records, each
  `Mot_File_List` header followed by `key_count` `FRAME_VECTOR_EX_DATA` keys, so the walk
  keeps the `FRAME_VECTOR_EX_DATA *` cursor and the per-header view (serialized-file traversal).
- `GetFootPoly`: `*(CCPolyCopy *) found = *(CCPolyCopy *) &polys[...]`. `*found = polys[...]`
  uses `CCPoly`'s implicit copy, which MWCC emits differently from the plain record copy.
