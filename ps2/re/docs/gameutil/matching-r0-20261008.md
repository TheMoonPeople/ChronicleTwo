# MotionProc time-key source form

`MotionProc__FP8mgCFramefP8Mot_ListP9mgCCamera` at `0x0014BEC0` is native. Its
body is `0x94C` bytes; the manifest's `0x950` extent includes one zero
alignment word.

The search bounds and midpoint use signed arithmetic. Key-frame values and
the count-minus-one upper limit are unsigned; the two unsigned-to-float
conversion sequences follow. Vertex targets are one-based indices: the
intermediate vertex path converts the target to an unsigned index before
subtracting one, then uses the typed vertex array. Endpoint paths use direct
array indexing.

The lower and upper endpoint tests are independent, which preserves the
retail NaN path. A null vertex-list successor returns null immediately; a
different model frame returns its unconsumed node. The camera-target case
transforms the existing temporary without interpolating it first. The motion
type is read after `GetFrame`, despite m2c's lifted pseudocode read.

`QuatSlerp` is LOCAL in retail and `static` in source; it is the only
same-unit helper this overload calls.

The declaration order is `next`, `frame`, `vertex`, `driven`, `key`,
`vertices`, with the vertex-specific locals declared in the function's
declaration block and assigned only in the vertex case. `vertex` is unsigned.
The allocation uses `s1` for next, `s2` for the resolved frame, `s3` for
camera and `s4` for key. In the vertex case the frame's dead register is
reused for the vertex index, the camera's for the driven frame, and the
root's `s5` for the vertex-array pointer.

The clamp is `count - 1`, which is exact only when the later vertex-index
expression converts `list->target` to unsigned before subtraction. Retail's
clamp emits `li v0,-1`, then computes next, then `addu v0,t0,v0`; the signed
target-subtraction form instead emits an immediate count decrement and shifts
later code by one word. Declaring the vertex array and driven frame before
`key` restores the camera/key registers; the vertex index, driven frame, key,
then vertex array order restores the last register pair as well.
