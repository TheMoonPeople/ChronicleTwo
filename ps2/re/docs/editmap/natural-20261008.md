# editmap natural access (2026-10-08 night)

Byte-identical object (`check_objects editmap`: 0x53EC bytes, 541 relocations).

## Replaced
- `ConvertParts`: `((int) part - (int) edit_parts) / 816` is the pointer difference
  `part - edit_parts`.
- `GetSameParts`: the `offset += 0x330` walk with a `CEditParts *slot` cast becomes
  `edit_parts[i]` indexed at each use in a `for` loop.
- `RemoveEditParts`: `(int *) part->house` read at `[1]` is `CEditHouse *house` and
  `house->npc_no[0]`; the `color_offset += 0x10` walk is `remove_info->color[j]`.
- `PlaceEditParts`: `((int *) place)[1]` is `place->base[0]`.
- Both `GetNearParts` overloads: `*(CEditParts **) ((u8 *) out + out_offset)` with a separate
  `count++` is `out[count++] = part` (writing `out[count - 1]` after the increment adds four words).
- `CEditParts *part` calls the inherited `CMapParts::GetPoly` and `GetColor` without the
  `(CMapParts *)` upcast.
- `CEditParts::allocation_address` is `u_long128 *` (editparts.hpp): the build stores the
  stack-mode block directly and the release passes it to `Free` without `(int)`/`(u_long128 *)`.

## Kept
- Functions under `#pragma global_optimizer off` keep their explicit byte offsets, which retail
  computes once and advances instead of rescaling the index at each use: `ClearAllParts`
  (`place_log + log_offset`, `fix_parts + initial_offset`) and
  `GetePlaceIDList` (`(s8 *) edit_parts + offset`, `part[0x70]`, `out + out_offset`).
