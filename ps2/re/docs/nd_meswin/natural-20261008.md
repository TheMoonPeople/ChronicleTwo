# nd_meswin natural access (2026-10-08 night)

Byte-identical object (`check_objects nd_meswin`: 0xBF28 bytes, 1364 relocations).

## Replaced
- `ClsMes::GetTextLineDataTop`, `GetTextLineDataTop_system`: the message file's line index is a
  short count, a further short (`entries[0]`, not read here), then `count` pairs of `u16` line id
  and text offset relative to `entries + count`. The pairs are read as
  `(u16) entries[i * 2 + 1]` / `(u16) entries[i * 2 + 2]` in a plain `for` loop, replacing the
  `off += 4` byte walk and the `(i << 2) + (int) entries + 4` address.
- Both `MakeMesWinTbl_value` overloads: redundant `(char *)` casts on `char text[]`.
- `ClsMes::GetCaptionOff`: reads `options->caption_off` without the `(s8)`
  conversion now that `SV_CONFIG_OPTION::caption_off` is `s8` (mapselect).
- `ClsMes::text_ptr` is `char *`: event_func stores and passes message text through it, and
  every other user (nd_meswin, event, editevent, editmode, helpmes, pbuggy, fishing, menucls1,
  dng_event, dng_hud) only clears it.
- `MovieCCAnalyze`: the caption loop compares `cursor < text + size` as pointers instead of through
  `(unsigned int)` conversions.
- `GetTextLineDataTop`/`GetTextLineDataTop_system` return the message text as `u16 *`
  (nd_meswin.hpp), converting the `short` line table position once, so `MakeMesWinTbl_item`,
  `GetMesWidth_system`, `MakeMesWinTbl` and `NeedMesWinWH` take the text without casts.

## Kept
- `signed char *` views of message text in the escape and `@` scanners: character-signedness
  conversions of the same text, not reinterpretations of other data.
