# mg_dataset: natural typed access (2026-10-08)

## Replaced

- `conv_new_text`: the source name is read as `*src` and `src[1]` instead
  of through `(s8 *)` views of the `char *` parameter.
- `htoi`: the length scan walks `char *end = text`.
- `mgSetFrameAttr`: the frame name scan reads `*text` and `text[1]` directly.
- `mgCMDTBuilder::EndData` stores each closed section's offset and count in
  the named `MDT_HEADER` fields, selected by `mgMDTDataType`, instead of
  `((int *) header)[3..14]`; the section state resets to `MG_MDT_DATA_NONE`.
- `mgCMDTBuilder::EndFaces`: `header->faces_size` instead of
  `((int *) header)[9]`.
- `mgCMDTBuilder::EndData`: section offsets are `end - (char *) header`, like `BeginFaces`,
  and the cursor rewinds with `end = data`, instead of the `cursor`/`section_start` integer
  views; the unused `section_start` union member is removed from mg_dataset.hpp.
- The unused `face_block` union view is removed from mg_dataset.hpp.
- `mgCopyFrame`: `table[i]->parent` is already `mgCFrame *`.
- `mgCreateBBoxSphere`: `vertex` is `float (*)[4]`, so the first point is `vertex[0]` rather
  than `(float *) vertex`.
- `mgLoadMDSFile`: the frame and matrix tables are `new (...) mgCFrame *[mds->object_num]` and
  `new (...) sceVu0FMATRIX[mds->object_num + 2]` instead of cast `operator new[]` calls.

## Kept

- `htoi`: `((u8 *) (back + (s32) text))[-1]` reads digits from the end.
  Retail adds the text address to the position (`addu v1,v1,a0`); both
  `(text + back)[-1]` and `(back + text)[-1]` put the pointer first.
- MDS and MDT sections are located from serialized byte offsets
  (`object_ofs`, `mdt_ofs`, `vertex_ofs`, `object->size`), and the writers
  measure sizes as byte differences from the header.
- `(int) mds % 16` tests the file buffer's alignment.
- `mgCMDTBuilder::EndFaces`: `face_end`/`face_block_addr`/`cursor` stay integer views; the
  face size is a byte difference between differently typed pointers and the end is rounded up
  with `& 0xF`.
- `mgCopyFrame`: `(mgCFrame **) operator new[](bytes, ...)`. `new (...) mgCFrame *[count]` keeps
  `bytes` in a temporary and shifts `count` again for the call (`s0` becomes `v1`).
