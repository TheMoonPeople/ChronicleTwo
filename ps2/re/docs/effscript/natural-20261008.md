# effscript natural access (2026-10-08 night)

Byte-identical object (`check_objects effscript`: 0xEA7C bytes, 1285 relocations).

## Replaced
- The unit's static `GetStackInt`, `GetStackFloat`, `GetStackString` and `SetStack` overloads use
  `RS_STACKDATA::val.f` / `val.s` instead of `*(float *) &val.i` and `reinterpret_cast`, and the
  `RS_INT` / `RS_FLOAT` / `RS_PTR` type names.
- `_CREATE_DAMAGE` and `_DMG_SET_DAMAGE` pass their error text to `printf` as a
  plain string literal instead of `(const char *) &"..."`.
- `_CHR_GET_FRAME_POS`, `_CHR_SET_FRAME_SHOW`, `_CHR_SET_LIGHT_COLOR`, `_SCN_GET_CHR_FRM_POS` and
  `_COLPRIM_SET_COORD` reach the inherited `mgCFrame *frame` that `CCharacter2::frame` (`float`)
  hides as `chara->CObjectFrame::frame` instead of through a `(CObjectFrame *)` cast.

## Kept
- `_SPT_VAN_SET_POS`, `_SPT_ADD_POS`, `_SPT_SET_VELO_POS`, `_SPT_SET_ACC_POS`:
  `stack = (RS_STACKDATA *) ((u8 *) stack + n * sizeof(*stack))`. `stack += n` lets MWCC fold the
  advance into the next use instead of updating the pointer register where retail does.
- `CEffectScriptMan::LoadBaseEffSpt` file buffers: `path_buffer`/`pack_buffer` stay `int` addresses; the pack buffer is
  placed after the path file with byte-size padding (`& 0x3F`, `& -0x10`).
