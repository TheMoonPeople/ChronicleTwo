## Kept

- `LoadGyorace`: `interpreter.SetScript((char *) &script, size)` casts the
  address of the `char script[0x4000]` array. Passing `script` makes MWCC
  set up the arguments in order (`a0` then `a1`); retail sets up the cast
  argument first (`addiu a1,sp,16` before `addiu a0,sp,16416`).
