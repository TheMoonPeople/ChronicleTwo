## Exact natural source proposal

The RGB editing cases use editor selections 2, 3 and 4 for red, green and
blue. `mgFOG_PARAM` stores these bytes at offsets 8, 9 and 10; its alpha
byte is at 11. The already native map-loading interpolation reads and
writes all four channels. A real `u_char color[4]` overlay on the existing
`r`, `g`, `b`, `a` fields therefore represents RGBA storage without
altering the `0x30` layout, the near/far fields or the coefficient vectors.

The direct indexed form is:

```cpp
int value = fog->color[edit - 2] + direction;
if (value < 0) value = 0;
if (value > 255) value = 255;
fog->color[edit - 2] = value;
```

This replaces the inherited conversion of the fog pointer into an integer
and its byte-address calculation. MWCC folds the array offset and the
subscript adjustment into retail's effective address; it does not
materialize an extra element pointer or index temporary. The entire
function remains **0/1356 words** with a native size of `0x1524`.
Retail's GLOBAL symbol also has size 5,412 (`0x1524`); the `0x1530`
manifest reservation contains twelve bytes of alignment padding.
The owned header's size comment now records the symbol size.

New probes with the same private RGBA overlay:

| Form | Result |
|---|---|
| Direct `fog->color[edit - 2]` load and store | **0/1356**, native `0x1524` |
| Reference to the whole four-byte array | 873/1356, native `0x1528` |
| Commuted array subscript | 0/1356, native `0x1524`; prefer the ordinary spelling |
| Named unsigned channel index | 873/1356, native `0x1528` |

The array-reference and index-local forms retain a separate subtraction,
shifting the remaining instructions. The previously recorded address-of-
element and element-reference probes are not repeated.
