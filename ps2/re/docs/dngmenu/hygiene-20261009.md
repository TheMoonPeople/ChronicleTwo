# dngmenu hygiene pass (2026-10-09)

Scope: `CMenuTreeMap::Step`, `CMenuTreeMap::MsgInit`, `DngTreeMapInit`,
`CDngFreeMap::DrawRoomOne`, `CDngFreeMap::DrawRoot`, `CDngFreeMap::LoadDngInfo`,
`DrawDngRoomInfo`, `DrawGeoramaMateria`. Checked with a PAL build
(`SCES_511.90: OK`) and `check_objects.py` (149/149).

## New names
- `DNG_TREE_MAP_SCREEN` (dngmenu.hpp) for the tree map's `key_arg_no`.
  Step switches its keys on it: 0 moves the cursor between floors, 1 handles
  the jump question or floor information, 2 the georama material list. Step
  sets 1 after opening the question/information and when the list closes, 2
  for the list, 0 on cancel; InitEnd and the constructor set 0; Draw shows
  the help line only at 0 and tests 1 with `DngAskMessageDrawFlag == 1`.
  These are the "key contexts 0/1/2": the key helpers Step calls take no
  context argument.
- `DNG_TREE_MAP_MATERIA_PAGE = 14`: DrawGeoramaMateria draws
  `page * 14 .. + 14`, prints `GeoramaMateriaNum / 14 + 1` pages, and Step
  turns to the second page only when `GeoramaMateriaNum > 14`.

## DNG_FLOOR_FLAG_CLEAR
`DNG_FLOOR_FLAG_UNK_2` (savedatadungeon.hpp) is `DNG_FLOOR_FLAG_CLEAR`: the
map debug display labels bit 0x2 "Clear" (`Table_2133[1]` beside
`bittable_2134[1]`), `CDngFreeMap` marks rooms that are open but lack it
(dngfloor.cpp), and Step lists a floor's georama materials only once it is
set. Renamed in savedatadungeon.hpp, dngmenu.cpp and dngfloor.cpp; the old
name still appears in dngfloor/notes.md.
