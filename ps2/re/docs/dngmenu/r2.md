# dngmenu: CheckGeoramaMateria and InitEnd forms

Durable status is in [notes.md](notes.md).

## CheckGeoramaMateria

The function reuses the group-search index for the subsequent item loop. The
search is finished before that reuse; the floor traversal and two
attribute-filter passes retain their separate index. This lifetime makes the
item counter/offset registers agree with retail and changes 6/112 differing
words to zero.

## CMenuTreeMap::InitEnd

The function uses a snapshot of the signed maximum floor count across lookup
calls. Loader locals are declared as block, texture-manager pointer, and map
image, while values are still initialized after `GetPackFile`. This preserves
the manager across the unrelated texture-loader call and produces retail's
saved-register reuse. The frame is 0xA0F0. The lower and upper room bounds are
separate checks. Selected sub/boss rooms are tested separately, sub first, and
assigned as marked cell then active floor. A two-float coordinate pair receives
the two X offsets before copying into the cursor. The successful file loader
supplies its output size, so that local needs no zero initialization. The
final state enables `cursor_view`, not the money board. All 224 words match
without profile calibration.

The register map is block s0, manager s1, image s2, read record s5; later
active room s6, marked cell s1, floor bound s2, loop index s3, and Y-element
address s0. All are compiler-generated from ordinary C++ locals.

A manager binding alone gives 217/224 differing words; it only matches
together with the floor-count live range that makes the frame exact.

## Other form findings

`DrawRoot` selects all four event tint values in one branch after their menu
defaults. `DrawRoomOne` has the glyph destination rectangle Set call at
0x1EDD28 and calculates unvisited-overlay corner coordinates before the drawing
calls; the far corner uses the origin plus 20/30, preserving retail's floating
operation order.

The `medal_xytbl` reads in `DrawDngRoomInfo` are signed halfwords, not packed
rectangle words. Retail loads offsets 0, 4, 6, and 8 and assigns only the
highlight rectangle's left coordinate: indices 0, 2, 3, and 4 for timed clear,
fishing, spheda, and the final medal row; their X values are 168, 212, 234, and
146. Top, width, and height remain 0, 22, and 22. Index 1 contains 190 and is
unused.

`LoadDngInfo` retains remaining arena capacity before obtaining its top pointer
and rounds unsigned loaded byte lengths up by quadword quotient and remainder.
A 64-byte filename scratch buffer reproduces the 0x160 frame.

The three Step static initialization flags are signed bytes, matching retail
`lb`. Tree-menu Draw sets its integer help state in a short-circuit branch,
removing boolean materialization. Free-map Draw encloses drawing in the
positive active/alpha/texture condition, using `!(alpha <= 0)` to preserve
unordered-float behavior, and its texture check shares the function exit.

For view clipping, making the first clip a conditional expression adds a branch
and grows the body to 0x144. Testing the clip local, retaining the float
input, and changing to mutable input parameters do not fix the initial copies;
the match needs the unit's GPR helper seed `0x30`. A named first-line X
coordinate in MsgInit leaves 7/116 words unchanged. For georama drawing,
moving the right-column declaration earlier leaves the wrong spill and 0x404
body.
