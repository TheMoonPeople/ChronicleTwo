# sceneload: natural typed access (2026-10-08)

## Replaced

- `CScene::LoadMapFromMemory`: the edit map's placement `new` takes the
  `u_long128 *` from `Alloc` without a same-type cast.

## Kept

- `*(volatile u_int *) timer0_count` reads the EE timer 0 count register
  for the load timing printouts.
- `LoadMapData` returns the load buffer as its nonzero success value (`return (int) load_buf`);
  callers only test it against 0.
- `CScene::LoadMapFromMemory`: `(CMapSky *) operator new(...)` then `Initialize()`. The
  `new (...) CMapSky` expression tests the copied register after the `move` instead of `v0`.
