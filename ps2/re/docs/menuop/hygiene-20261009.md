# menuop hygiene pass (2026-10-09)

`CSaveMenuClass::KeyStep`. Checked with a PAL build (`SCES_511.90: OK`) and
`check_objects.py` (149/149).

## Changed
- The save-done and load-done sounds are `SYSTEM_SE_COMPLETE` (0x1F, new in
  snd_mngr.hpp). Every system-bank 0x1F plays on a finished transfer: KeyStep's
  `SAVE_LIST_PHASE_SAVING` -> `SAVE_DONE` and `LOADING` -> `LOAD_DONE`, the
  sub-game card's `SUB_SAVE_WRITING` -> `WRITE_DONE` and `SUB_SAVE_LOADING` ->
  `LOAD_DONE` (menuop), the geostone download end (editmenu), the HDD
  install result (title), and inventmn's card format end (`FORMAT_END`),
  album save end (`SAVE_END`) and album load end. Only the two KeyStep sites
  are in this scope.

## Left literal
- `phase = 0` on the slot/card-info/file-read pages (no phase enum there),
  `SetAbsPos(5)`, the `SetDlInfoMsg` flags, the 13-file count, map numbers
  0x29/0xB, chapter and progress values, the `MenuKeySelectCheck` mode
  argument and the zero-based `YesNoCursor()` position. `(float) top`
  converts int to float. The header block agrees with `main.symbols.txt`
  (0x2C7710 / 0x1A64).
- Outside this scope: `MenuSePlay(0x1F)` in the sub-game save steps,
  editmenu and title, and `MenuSePlay(31)` at inventmn 5189/5265/5342.
