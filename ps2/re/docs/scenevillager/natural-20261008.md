# scenevillager: natural typed access (2026-10-08)

## Replaced

- `CScene::LoadVillager`, `LoadSubVillager`: the model buffer local is the `u_int *` pack that
  `GetChrFileSize` and `LoadChara` take, converted once from `read_buff`, instead of
  `(u_int *)` casts of a `u_long128 *` local at both calls.

## Kept

- `CScene::RegisterVillager`: `(CVillagerPlaceInfo *) operator new(...)` then an inline clear.
  `CVillagerPlaceInfo()` is an out-of-line function (vlgr_info, 0x31F3B0), so a `new` expression
  would call it instead of the inline `memset` and `map_no = -1`.
