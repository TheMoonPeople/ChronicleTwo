retail relocation masks, an exact relocation offset/type multimap, and a native
section within the retail layout extent. Unknown relocation types or invalid
bounds reject zero. Actual symbol body size is retained separately from
layout padding. The scorer does not check resolved targets against retail,
source hygiene, complete-object acceptance or promotion eligibility.
