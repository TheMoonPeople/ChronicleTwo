The historical hybrid reproduces all 149 accepted34 raw objects and the
entire accepted34 executable. Its private profile omits all 34 placement
rows, retaining every other policy field and all 81 floating-expression
rows. This strengthens the global alternative's native-code evidence beyond
the earlier 25 guarded diagnostic gains /zero previous-zero regressions.
It remains a private prototype, with explicit name-filter/scope limitations
and a distinct before-template exception; no production policy is activated.

## Preserved failures and test scope

The first pn15 image-ID preflight confuses recorded config digest with
Docker's manifest-list identity and fails before building. A corrected
read-only identity check preserves that receipt. The first pn16 build
passes production Cargo compilation, then fails full tests because the
saved source omits two exact example fixtures. A separate corrected
private recipe tests only `compiler_cli`: one test passes and six genuine
compiler fixtures are ignored. Full Rust/example and genuine MWCC builder
tests are unrun for this historical driver. Production pn15's separate
13 genuine CLI /30 Rust acceptance is unchanged and is not attributed to it.

The first mg_tanime attempt completes two genuine passes, then a login
shell loses the assembler PATH. One authorized launcher-only `bash -c`
retry uses unchanged source/profile/driver/flags and passes. No other
unit is retried: 283 actual game compiler passes include those two setup
passes. Two reporting-only assertions are also preserved: wrongly counting
all legacy float rows, and expecting the entire completion body to omit
pn11's documented pending-new-walk guard. Corrected static audits introduce
no compiler or object-checker rerun.
