## Kept
- `CVillagerMngr::GetAppearVlgr`: `*(CVillagerPlaceInfo **) ((u8 *) (time * sizeof(void *)) +
  (int) schedule + alternative_offset + 8)` is `schedule->place[alternative][time]`, and the
  `places` / `villager_ids` stores go through byte offsets that advance only when a place is
  written. Indexing `place[alternative][time]` (dropping `alternative_offset` and
  `fallback_offset`) rotates `a3`/`t0`/`t1` between the place, the alternative offset and the
  output offset in both loops. `found` increments conditionally, so `places[found]` cannot become
  the retail induction offsets.
