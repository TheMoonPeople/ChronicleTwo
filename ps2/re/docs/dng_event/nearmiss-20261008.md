# Flat-position search near-miss notes

`SearchMapFlatPosition__FPfP11CAutoMapGen` is native and matches; the source
forms it depends on are in [notes.md](notes.md). Natural forms excluded while
closing it (all against the 0x410 retail body):

- A direct-call, fully indexed base (both the placed-parts and grid-cell walks
  as array indexing) gives 219/264 words and a 0x420 body; declaring the
  polygon, hit, attempt, axis and part-query locals at use keeps that result.
- Separating placement and collision receivers with both walks indexed gives
  227 (pointer) or 234 (reference) words, 0x420.
- Caching the grid array before indexed traversal gives 237/266 and 0x428; a
  cell reference is the same; direct cell indexing 236/268 and 0x430;
  separating the occupied count 237/262 and 0x418.
- A typed const placement-array base with indexing gives 212/264 at 0x420;
  the double-negated sentinel test enlarges these forms to 0x428.
- An `AUTOMAP_ATTR` local keeps 219/264; a u16 attribute local gives 222/266
  at 0x428 (the `CAutoMapParts` field is s16). Const parameters, SDK vector
  aliases and unsigned grid indexing do not recover the pointer slots.
- Scoped optimization level 4 or global optimization on retain the indexed
  result; level 2 emits 0x4DC; global optimization off 0x420 with 240/264.
- `DngMainScene` is GLOBAL in retail and is not localized.
