## Frame: the output spill slot

Retail spills `a0` (`out_pos`) to `sp+0xE0`, `a1` (`map_gen`) to `sp+0xDC` and
the map pointer to `sp+0xD8`. Spill slots are allocated after the named
locals:

- `0x50A760` walks the spilled nodes in ascending virtual register order.
- Each slot comes from `0x48B080`, a downward bump allocator: frame
  `[0x57C75C]` grows by the type size, is rounded up to the alignment
  (`0x459120`), and the slot offset is stored at object `+0x2C`.
- A node whose object has flag `0x10` at `(obj+0x28)+0x2E` gets a 16-byte
  slot.

With `float *out_pos` the first slot takes 4 bytes and the frame is `0x2BD0`.
With `sceVu0FVECTOR out_pos` the parameter keeps the vector type's 16-byte
alignment, its spill slot is 16 bytes and the frame becomes `0x2BE0`. This
replaces the scalar alignment attributes, which only padded the frame.

## Receiver: two pointer webs

Retail stores the `GetMap` result to `sp+0xD8` in the delay slot of the null
test. It then passes `v0` (`move a0,v0`) as the `GetPlacPartsTable` receiver,
without a reload. The collision loop reloads `sp+0xD8`.

PCode captured at the first GPR colouring (`0x4AF0F0`) shows how each source
form represents this:

| Source form | PCode | Code |
|---|---|---|
| `if ((map = GetMap(…)) == NULL)` | `mr r52,r2`, test `r2`, receiver `r52` | receiver reloads `sp+0xD8` (1 word) |
| `map = GetMap(…); if (map == NULL)` | test and receiver `r52` | test reloads after the store (27 words) |
| Inline wrapper or plain user copy (`map = active`) | copy propagation replaces every later `map` use; one long-lived vreg | 27–73 words |
| `CMap *const scene_map = GetMap(…); if ((map = scene_map) == NULL)` | `mr r53,r2`, test `r2`, receiver `r2` | retail |

A local assigned from a call whose uses all come before the next call gets no
virtual register: its uses read `r2` directly. The copy into `map` survives
only when IR copy propagation cannot substitute the source into `map`'s later
uses. A plain copy between two `CMap *` locals is always propagated, which
eliminates `map` and leaves the lookup local long-lived and spilled.
Propagation stops when the source is redefined after the copy (diagnostic
only, a dead `active = NULL;`), or when the two types differ by a top-level
`const`. Retail therefore had two pointer variables for the map. The const
lookup local is the natural form that keeps them separate.
