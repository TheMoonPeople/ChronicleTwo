# movie: natural typed access (2026-10-08)

## Replaced

- `StrFile::unk_20` was the `flag` member that ends the SDK's `sceCdlFILE`; it is now part of
  `fp` (libcdvd.h, see dataread). `StrFile` stays 0x34 bytes.
- `CMovie::Play`: the decoder fallback and stream threads take `defMain`/`stepMain` as the thread
  entry directly. `defMain` never returns, so it is declared `void` like the other entries.

The remaining byte-offset forms are kept.

## Kept

- `audioDecBeginPut`: `(u8 *) ((int) dec->hdr + dec->hdr_count)`. Retail
  forms `&dec->hdr` first (`addiu t2,a0,4`) and then adds the count;
  `dec->hdr + dec->hdr_count` adds the count to `dec` first.
- `viBufAddDMA`: `(u8 *) buf->data + n * 0x800` for the DMA tag addresses.
  Quadword indexing (`buf->data + n * 0x80`) keeps the `sll 11` but evaluates
  the base load and index in the opposite order.
- `setImageTag`: `data = (u8 *) data + 0x400` steps a `void *` parameter; the
  parameter type is part of the mangled name.
- `videoCallback` ring code (`(u8 *) buf + buf->size`, `(u8 *) buf` as the
  wrap source) and `videoDecPutTs` (`area - (u8 *) dec->vibuf.data`) measure
  byte positions in raw stream buffers that hold mixed-size data.
- `GifTagData` locals initialised from the `at_1276__2`/`at_1287__2` quadword constants.
- `setImageTag`: `sceGifPkOpenGifTag(&packet, *(u_long128 *) &giftag)`. Retail forms the local's
  address (`addiu v0,sp,144`) and loads through it; `giftag.value` loads `144(sp)` directly.
- `iop_buff`/`iop_zero` hold IOP heap addresses as `int`; DMA tags and stream buffers mask
  addresses with `& 0xFFFFFFF` / `| 0x20000000` (physical and uncached segments).
- `videoDecSetStream(..., (int (*)(sceMpeg *, sceMpegCbData *, void *)) videoCallback, ...)` and
  the `pcmCallback` counterpart: both callbacks take `sceMpegCbDataStr *` (part of their mangled
  names) while `sceMpegCallback` takes the SDK's `sceMpegCbData *` union.
