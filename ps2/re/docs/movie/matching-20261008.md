The retained source has three guarded functions. Measurements use integration
`d7590de`, MWCC 3.0-011126, canonical flags, the existing local optimization
settings, and the Satan’s Fiddle adapter. The complete movie object remains

## Interrupt handlers

Retail `handler_endimage` finishes with `sync; ei`; `vblankHandler` has these
instructions at both its empty-frame early return and normal return. External
`EIntr()` calls cannot reproduce them. Prior apparent SDK-enable probe matches
in `media-review1g-evidence` were unchanged companion functions that still
contained inline assembly: the same output filename was reused and overwrote
the earlier companion’s result. They are not evidence for a native intrinsic.
Reconsider when the compiler/SDK can generate the exact inline sequence from
an allowed intrinsic. No replacement assembly is introduced.

## DMA restart

All nine differences belong to the first wraparound branch. Retail uses `a3`
for `buf->n` and `a2` for the address mask; the draft swaps them. The differing
retail offsets are +0x78, +0x90, +0x94, +0x98, +0xCC, +0xD4, +0xDC, +0xF4,
and +0x108. The rest of the function matches, including IPU busy-wait timing.
`objdump` suppresses runs of zero words; its displayed absence of NOPs in
both columns must not be mistaken for missing busy-wait instructions.

Measured GPR masks 0, 0x10 and 0x30 have no effect. Direct tag-address masking
instead of the existing inline `DmaAddr` worsens the difference to 27/200.
Unsigned address subtraction, unsigned ring size, 2048-byte multiplication,
reordering the independent tag calculation after MADR wrap, and representing
the saved tag as `void*` all retain 9/200. A named ring-block count changes it
to 12/200. These candidates are reverted; no source edit is retained.
Reconsider with evidence for natural DMA address/count types or verified
allocator/callee-history state that distinguishes these temporaries. Neither
the measured helper masks nor a floating-order selector explains this integer
allocation difference, so no profile row is proposed.

`Play`’s whole-draft relocation diagnostic
is not a linked movie failure: the canonical complete object passes.

## Nearmiss follow-up

Six new hypotheses leave the guarded restart at 9/200. Calculating the tag
address before ring extent differs by 12/200; using the extent directly at
both uses gives 10/200; capturing the saved MADR before endpoint comparisons
gives 21/200. Narrowing the extent to its branch or giving each path its own
mode retains 9/200. Capturing a named typed DMA-tag pointer expands the saved
register differences to 27/200 and leaves the mask/count swap unresolved.
All candidates are reverted. The prior helper-mask/type/order trials were
read first and not repeated. No integer-allocation profile policy is validated.

Reconsider with actual evidence that distinguishes the ring-count and address
mask lifetimes under this compiler. The source and assembly guard are unchanged.
