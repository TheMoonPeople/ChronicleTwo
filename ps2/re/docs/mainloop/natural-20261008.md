# mainloop natural access (2026-10-08 night)

Byte-identical object (`check_objects mainloop`: 0x4A8C bytes, 1550 relocations).

## Replaced
- `ReLoadFontTexture`: the `offset += 4` byte walk over `FontDataAdr` / `FontTex` is
  `FontDataAdr[page]` / `FontTex[page]` in a `for` loop. Keeping a `TM2_head **font_data =
  &FontDataAdr[page]` local changes the allocation; indexing at each use matches.
- `gcGEO_COMPLETE`: the edit data handle is a `CEditData *`, the type `GetEditData` returns,
  instead of a `void *` cast back to `CEditData *` for the call.

## Kept
- `(char *)` conversions of loaded buffers: ordinary conversions, not puns.
- `MainLoop` read buffer setup: `buffer_address` stays an `int` address for the 64-byte alignment
  (`% 64`, rounded to quadwords).
- `MainLoop`: `mgInitVSyncCallBack((int (*)(int)) VSyncCallBack)`. The callback is a `void` function
  and the `int (*)(int)` parameter type is part of `mgInitVSyncCallBack`'s mangled name.
- `MainLoop`: `SubGameSaveData = (CSubGameData *) main_buffer` places the sub-game save block at the
  start of the `u_long128` main heap buffer, ahead of the region handed to `stSetBuffer`.
