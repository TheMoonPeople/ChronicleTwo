# mapload: natural typed access (2026-10-08)

## Replaced

- `mapFUNC_POS`: the `float matrix[4][4]` local is passed to `mgUnitMatrix` without a
  `(float (*)[4])` cast.
- `CFuncPoint::frame` is an embedded `mgCFrame`, so the bound is attached with
  `mapNowFuncPoint->frame.SetBound(...)` rather than through `(mgCFrame *) &frame`;
  `cfgWater` (`CWaterFrame *`) calls the inherited `SetPosition` without an upcast.
- Map piece frame: `CMapPiece` inherits `CObjectFrame::GetFrame`, so `piece->GetFrame()`
  replaces `(mgCFrame *) ((CObjectFrame *) piece)->GetFrame()`.
- `mapFUNC_EFFECT_NAME` (`mgCFrame::BoundInfo`) and `cfgWATER_SURFACE_NUM`
  (`CWaterFrame *[water_surface_num]`) use placement `new` expressions instead of cast
  `operator new` calls.
