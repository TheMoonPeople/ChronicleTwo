# runscript_opcodes: natural typed access (2026-10-08)

Byte-identical object (`check_objects runscript_opcodes`: 0x795C bytes, 1297 relocations).

## Replaced
- `nowMonster` (`CActiveMonster *`) calls `GetEntryObjectPos` and is passed to
  `piyori.Set` without `(CCharacter2 *)`/`(mgCObject *)` upcasts; the implicit conversion
  sets up the same argument.
- `nowMonster` calls the `CActionChara` methods it inherits (`GetPosition`, `GetRotation`,
  `SetMotion`, `EntryObject`, `EntryDamage2` and others, 34 calls) without the `(CActionChara *)`
  upcast; `CActiveMonster` hides none of them.
- `monster = nowMonster` without the `(CCharacter2 *)` upcast; `CScene::GetStack` already
  returns `mgCMemory *`.
- `ActiveMonster->active[id]` and `nowMonster` (`CActiveMonster *`) assign to
  `CActionChara *`/`CCharacter2 *` locals without upcasts; `GetPlaceParts` already returns
  `CMapParts *`; `_LOAD_RESERV_IMG` takes `Alloc`'s `void *` result directly.

## Kept

- `_GET_INDEXOBJ_SIZE`: the entry object is
  `(CHARA_ENTRY_OBJECT *) (object_index * sizeof + (int) &monster->entry_object)`.
  Retail forms `&monster->entry_object` (`addiu v1,v1,320`) and adds the
  scaled index before loading `size` at offset 4. Both
  `nowMonster->entry_object[object_index].size` and an
  `entry_object` base local fold the 320 into the load (`lwc1 $f12,324(v0)`).
