# scriptinterpreter: natural typed access (2026-10-08)

No source change.

## Kept

- `*(s16 *) &buffer[position]`, `*(int *) &buffer[position]` and
  `*(float *) &buffer[position]` read operands from the serialized script
  bytecode, a `char` stream whose operands sit at byte offsets rather than
  typed elements. `GetArgBin` pads `position` to a four-byte boundary before
  the int, float and string values, so those reads are aligned; the 16-bit
  argument count and tag index are read at the stream's current position.
- The tag hash setup carves the bucket table and the chain links from one
  run of storage with a `u8 *` bump pointer.
- `PreProcess` reads the script text through a `u8 *` view.
