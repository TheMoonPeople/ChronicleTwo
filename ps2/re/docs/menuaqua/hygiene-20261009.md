# menuaqua hygiene pass (2026-10-09)

Scope: `CAquarium::ColCheck`, `DrawFishParam`, `CAquarium::Step`. Checked
with a PAL build (`SCES_511.90: OK`) and `check_objects.py` (149/149).

## New names
- `BREEDFISH_FLAG_RAISED = 0x1` (userdata.hpp): ParamStep sets it on every
  feeding, CombineFish sets it on the newborn, the fishing-tournament entry
  (menusys) refuses a fish with it, generated race fish clear it, and
  DrawFishParam draws the weight digits only when it is set (three
  placeholder glyphs otherwise). `BREEDFISH_USED::flags` now refers to
  `BREEDFISH_FLAGS`.
- `AQUARIUM_TANK` (userdata.hpp): `CFishAquarium::GetAquariumFishTop`'s
  switch maps 0/1/2 to fish_tank/sub_tank/breed_tank; `active_tank` and the
  tank arguments use that numbering.
- `AQUARIUM_COMMAND` (menuaqua.hpp): Step's `switch (ids[i])` reads
  `menu_id_tbl_3721`; each arm opens FISH_INFO, FOOD_SELECT, RENAME_GUIDE,
  TAKE_OUT, MOVE_SELECT, SWITCH_TANK_SELECT. Tanks 1 and 2 list {0,3,4,5}
  padded with -1 (`menu_max_tbl_3720 = {6,4,4}`). The table data itself is
  left numeric.
- `AQUA_CAMERA_CTRL` (menuaqua.hpp): MenuAquaKey's active mode lets both
  sticks steer the camera (distance clamped 130..262) at 0 and only the
  right stick at a fixed 150 at 1; Step sets 1 only for
  `AQUARIUM_MODE_FOOD_POSITION`, where the left stick moves the food.
- `AQUA_FISH_ACTION_PHASE` (menuaqua.hpp): `CAquaFish::MoveActionBattle`
  chases at 0, starts the battle motion at 1 and moves to 2, swings at 2 and
  returns to 0 on `col_flags & 0x10`; NextThink sets 3 for a battle rest and
  Thinking moves 3 to 4.

## Changed
- ColCheck: tank tests use `AQUARIUM_TANK_SECOND/BREED`; the battle contact
  test is `phase == AQUA_FISH_ACTION_APPROACH` -> `AQUA_FISH_ACTION_SWING_START`.
- DrawFishParam: `BREEDFISH_FLAG_ELECTRIC` (name colour) and
  `BREEDFISH_FLAG_RAISED` (weight shown).
- Step: nine `MenuSePlay(SYSTEM_SE_WINDOW)` (0x13), two
  `BREEDFISH_FLAG_ELECTRIC` refusals (message 0x12D), `LANG_JAPANESE` in the
  button-row choice, `AQUARIUM_TANK_BREED` for the breeding destination,
  `AQUARIUM_COMMAND_*` case labels, `AQUA_CAMERA_CTRL_*`, and no
  `(u_long128 *)` cast on `food_stack.Alloc(...)` (Alloc already returns
  `u_long128 *`).

## Left literal
- Item numbers (0x168 electric food, 0x13B), message ids (0x12C..0x139,
  0xC8, 0xD2, 0xDC, 0x320/0x384/0x3E8), help ids 0x32/0x34,
  `MenuSePlay(0x1E)` and the `Aqua_SpSndID` sounds 3/4: no enum and the
  meaning is not established.
- Outside this scope: `BREEDFISH_FLAG_ELECTRIC` at menuaqua 2716/2720/3652/
  4034/6620 and userdata 4359/6284; `BREEDFISH_FLAG_RAISED` at menuaqua
  2693/4461 and menusys 12038; `AQUA_FISH_ACTION_*` in MoveActionBattle,
  NextThink and Thinking; `AQUARIUM_TANK_*` in GetAquariumFishTop and
  FishIntoAquarium; `MenuSePlay(0)` in SelectFish; `AquaCameraCtrlMode`
  0/1 in MenuAquaInit and MenuAquaKey (`AQUA_CAMERA_CTRL_FREE/FOOD`).
