# charasetup: natural typed access (2026-10-08)

## Replaced

- `GetCharaMemAllocPtr`: the allocation loop reads `mem_table[row][index]`
  and configures `stacks[index]` instead of stepping a table byte offset
  (`*(int *) (table_offset + (int) mem_table[row])`) and a stack byte offset
  (`(mgCMemory *) ((u8 *) stacks + stack_offset)`). The stack is indexed at
  each use; an `mgCMemory *stack = &stacks[index]` local exchanges the two
  offset registers with the element pointer.
- `SetupMints`, `SetupMonica`, `SetupMonster`: `characters[5]` holds `CActionChara *` (one
  downcast where `GetCharacter` fills it), so `ResetParent`, `SetRef`, `move_type`,
  `attack_type` and `chara_type` need no per-use cast; `name` and `CopyOutLine` are inherited.

## Kept

- `LoadActionFile((char *) read_buffer, ...)` in the setup functions passes
  the `u_long128` file buffer to the loader's byte-buffer parameter.
