# nameregi: natural typed access (2026-10-08)

## Replaced

- `CNameRegiMenu::DrawSelectedWord`: the texture block is `NameRegiTex1->block` instead of
  `*(s16 *) NameRegiTex1`.
- `search_txt_asci`: `s8 *character = text` without a same-type cast.
- `NameRegistInit`: `cursor_img` takes `GetMenuMainIMGPtr`'s `u_char *` directly (menumain).

## Kept

- `CNameRegiMenu::KeyStep`: `DecodePassword(password, (u8 *) decoded, 0x10,
  (u8 *) key_text, 0x14)` casts arguments that are already `u8` arrays and
  pointers. Without the casts the argument registers are set up in source
  order (`a0`, `a1`, `a2`, `a3`); retail sets up the two cast arguments
  first (`a1`, `a3`, then `a0`, `a2`).
