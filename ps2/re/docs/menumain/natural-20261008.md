# menumain natural access (2026-10-08 night)

## Replaced
- `MakeMenuTopic`: the topic width is measured with
  `TopicFont.CalcDrawWH(TopicFont.str, ...)` instead of passing the font object's address as
  `char *` and casting it back to `CFont *`; `str` is `CFont`'s first member.
- `MenuInternInit`: the message window's placement `new` takes the
  `u_long128 *` from `Alloc` without a same-type cast.
- `MenuMainExit`: `camera` is the `mgCCamera *` that `CScene::GetCamera` returns, instead of a
  `CScene *` cast back to `mgCCamera *` at each call.
- `menu_GetBattleAreaScene` returns `DNG_BATTLE_AREA *` (menumain.hpp), the type of
  `&scene->battle_area` it returns; the mangled name has no return type. Callers drop their
  `(DNG_BATTLE_AREA *)` casts, including the remaining dngmenu and menusys consumers.
- Icon form lookups use `GetMenuMainIconChar`'s `char *` result without a cast.
- `MenuMainExit`: `GetMainScene` already returns `CScene *`.
- `GetMenuMainIMGPtr` returns the frame image as `u_char *` and `GetMenuMainPosCfgBuffer` the
  layout script as `char *` (menumain.hpp), so `MenuMainImageDataEnter` and `MenuInternInit`
  use them without casts. Callers in editmenu, menushop, nameregi, menumap, menuchr and menuop drop their casts too.

## Kept
- `CursorSaveOptionState`: `(u8) !*(int *) &save_data->config`. Retail forms the full address of
  `config` (`lui`/`ori`/`addu`) and loads at offset 0; `save_data->config.cursor_save`, a
  `SV_CONFIG_OPTION *` local and `save_data->GetConfig()->cursor_save` all fold the offset into
  the load (`lui 0x2` + `lw -14988`) and shorten the function by one word.
