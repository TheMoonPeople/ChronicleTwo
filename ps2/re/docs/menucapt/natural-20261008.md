## Kept

- `MenuChapterInit`: `LoadFile2((char *) "snd2/sp/SP_007.snd", sound_buffer,
  (int *) &file_size, 0)`. Without the cast on the string literal, MWCC sets
  up `a2` (`&file_size`) before the literal's address in `a0`; retail sets
  up `a0` first. `file_size` is `u_int` for the unsigned size arithmetic
  around the call, so `&file_size` keeps its `(int *)` conversion.
