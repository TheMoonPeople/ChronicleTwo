## Semantic selector precedence

The earlier [36-row candidate](selector-context-20261008.md) reaches
20 words. It deliberately excludes broad rows overridden by narrower
Japanese policies. The upstream wrapper supports this composition:
the greatest source-identity specificity wins, while contradictory
policies at equal greatest specificity are rejected.

Every new row uses the real unit `sphida.cpp`, enclosing function
`DrawStatusSprite__7CSphidaFv`, binary32 value and callee
`DPrimEnterSprite__FP11mgCDrawPrimiiiiffff`. `JP` is the actual
`LanguageCode == LANG_JAPANESE` condition, represented by
`control: {kind: condition, values: [0]}`. Each sibling is a real
formal floating argument. No source position, occurrence ordinal,
instruction address, new call or arithmetic-operand selector is used.

`Ordinary` means `evaluate_first: false`, without `evaluate_before`.
`Before 7` means `evaluate_first: false, evaluate_before: 7`.
Every new row asserts `expected_matches: 1`.

default ordinary schedules are required. Four retained broad early rows
now assert one match instead of two: Y=384 selected by width=58,
gauge Y=406.4 and height=28 selected by width=68, and suffix Y=406.4
selected by X=482. Their Japanese arguments are consumed by the narrower
ordinary rows; their other-language arguments retain early evaluation.
The remaining repeated identities keep the counts in the prior notes.

The resulting profile contains **41 rows**, with 48 asserted argument

The four corrected schedules are:

## Source and data hygiene

The guard and assembly marker are removed manually after the private
complete-unit candidate passes. The function uses ordinary C++ calls,
typed arrays and existing fields throughout; no assembly, vtable store,
steering helper, dummy local, pointer walk or type pun is introduced.

The status-bar name is the eleven-byte zero-terminated `"sphida_bar"`
at `0x00377728`, followed by five zero alignment bytes. All three unit
uses now inline that literal, replacing its extern declaration and
assembly rodata marker. `InitStatusSprite` and `DrawParCounter` remain
exact. The other existing unit data owners are unchanged.

Retail binds the promoted symbol GLOBAL and gives its body size as
`0x111C` at `0x002EF390`. The header now records that size; the `0x1120`
comparison extent includes four zero alignment bytes.
