# actscript natural access (2026-10-08 night)

Byte-identical object (`check_objects actscript`: 0x47F4 bytes, 1111 relocations).

## Replaced
- The unit's static `GetStackFloat`, `GetStackString` and both `SetStack` overloads read and write
  the `RS_STACKDATA::val` union members (`f`, `s`, `p->val.i`, `p->val.f`) instead of casting
  `val.i`, and test `RS_INT` / `RS_FLOAT` / `RS_PTR` instead of 0 / 1 / 3.
- `CActionChara *target` calls the inherited `CCharacter2::GetEntryObjectPos` without the
  `(CCharacter2 *)` upcast.
- `SetActionScript`: the script stack and call data are `RS_STACKDATA *`/`RS_CALLDATA *`
  locals cast once from `Alloc`, instead of `int` locals cast back at the `load` call.

## Kept
- `(CActiveMonster *)` / `(CCharacter2 *)` casts of held objects: downcasts, not puns.
- `_CHECK_CATCH`: the `int` result of `CheckKeri` goes through the `char *name` local
  (`name = (char *) ...; SetStack(stack, (int) name)`). Passing the call result straight to
  `SetStack` sets up `a0` before `a1`; retail sets up the cast argument `a1` first.
- Charging effect: `accume_effect` is `void *` and `AccumeSlot` (local to actscript) duplicates
  the layout of `ACCUME_EFFECT` from dng_main.hpp, which this lane may not edit. Typing the field
  as `ACCUME_EFFECT *` and naming that struct's fields would remove the casts.
