# sound hygiene pass (2026-10-09)

`CSound::Init`: nothing to do. MIDI_PORT `unk_00`, `unk_CC`, `unk_118`,
`unk_11C`, `unk_120` are only initialised; `unk_98` is only sent with EZMIDI
command 0xA0, whose meaning is unknown. `ezMidi(0x8010, ...)` is
`EZMIDI_RESPONSE | 0x10`, but the other EZMIDI commands in sound.cpp are raw,
so a command enum is a unit-wide change. `sceSifAllocSysMemory(1, ...)` has no
SDK mode constant; driver ports 0..15 are not `sndPORT` game ports;
`(void *) ezMidi(...)` converts int to pointer. The header block agrees with
`main.symbols.txt` (0x18A410 / 0x77C).
