# Costume drawing argument policy

`CMenuCostumeSel::Draw` is native and exact. Its help-box call selects
binary32 36.0 (`0x42100000`) for `DrawMenuFillBox__Fffffiiii`, with
`evaluate_first: true` and `expected_matches: 1`. The row places the box X
argument before the Y subtractions. No control or sibling-call selector is
required for this identity.

The row alone leaves eighteen words different on the earlier branch-form
pulse calculation. The accepted conditional-expression magnitude and
coordinate lifetimes resolve that source residual; see
[matching constraints](matching-constraints.md). The arrow's four-pixel
offsets are arithmetic operands, rather than eligible constant call
arguments. Extending an argument selector to those operands is unsupported
and unnecessary for the current match.

The declared body is `0x8D4`; terminal alignment occupies the remainder of
the `0x8E0` address span. Complete-object verification checks resolved
relocations as well as bytes, and the integrated PAL verifier passes.
