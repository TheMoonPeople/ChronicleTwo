# mapjump: natural typed access (2026-10-08)

No source change.

## Kept

- `MapJump`: `map_nos` points at `CSaveData::map_no` and indexes the run
  `map_no`, `sub_map_no`, `prev_map_no`, `prev_sub_map_no`; the area store
  is `*(int *) (map_nos + 4)`, which is `CSaveData::area_no`. Writing
  `save_data->area_no` re-forms the large field offset from `save_data`
  and changes the instruction count.
- `(u8 *) (ScriptBuffer->stack + ScriptBuffer->stack_used)` is the byte
  buffer the event script file is read into.
