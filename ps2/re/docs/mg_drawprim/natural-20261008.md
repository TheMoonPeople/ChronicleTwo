# mg_drawprim natural access (2026-10-08 night)

Byte-identical object (`check_objects mg_drawprim`: 0x1630 bytes, 54 relocations).

## Replaced
- `DepthTestEnable`, `DepthTest`: the private `mgCDrawPrimDepthState` overlay at `this + 0x20`
  is `draw_env.test` (TEST register, ZTE bit 16, ZTST bits 17-18). Retail first forms the
  register's address (`addiu t0,a0,0x20`) and updates byte 2 through it, which a
  `sceGsTest *test = &draw_env.test;` local reproduces; the `bits.zte`/`bits.ztst` u_long
  bitfields still compile to the retail `lbu`/`sb` byte updates (the 64-bit `daddiu` constants
  come from the u_long field type). Writing `draw_env.test.bits.*` directly loads the byte at
  `0x22(a0)` without the address and fails.
- `BeginPrim2(int, u_int, u_int, int)`: `*(u_int *) &prim & 0x7FF` becomes the whole-register
  GS view `*(u_long *) &prim & 0x7FF` already used by `BeginDma`; MWCC still emits `lw` + `andi`.
- `Data`, `DirectData`: `command_write` byte arithmetic becomes quadword steps on `write`.
  `Data` stores the quadword with `*write++ = quad` instead of reusing the `data` parameter as
  the cursor (a separate `u_long128 *slot = write` local changes the register choice);
  `DirectData` advances with `write += count`.
- `DirectData` returns the reserved quadwords as `u_long128 *` (mg_drawprim.hpp), the type of
  `write`, instead of a `u_char *` view that its callers cast back.

## Kept
- `mgCDrawManager::Draw` (`global_optimizer off`): the `offset = group << 2` byte offset into
  `packet_list` / `packet_num`. Retail computes the scaled index once into `s4` and reuses it for
  three loads in separate blocks; `packet_list[group]` / `packet_num[group]` re-emit `sll` at each
  use without the global optimizer (size 0x204 instead of 0x1F8).
- `mgCDrawPrim::Texture`: the cached texture is copied as
  `self->texture = *(mgCTextureFields *) source;` through the file-local
  `mgCDrawPrimTexture` view, which only places the copied state at the
  `texture` member's offset (0x58); the rest of the function uses the real
  members (`texture.Bilinear(bilinear)`, `command_write`, `texture.tex0_bits` /
  `tex1_bits`). `mgCTextureFields` mirrors `mgCTexture`'s fields with their real
  types (the GS registers as their packed `u_long` bits) but without its
  constructor and register unions, so the copy is a plain memberwise copy.
  Assigning `texture = *source` uses `mgCTexture`'s implicit copy, which keeps
  `source` live in a saved register and copies part of the record through a
  call. Writing the copy as `*(mgCTextureFields *) &texture = ...` forms the
  member's address in a register first and makes the function 4 bytes longer
  (`bytes differ`, `.private/fixes-r3c/b2-check.log`), so the view through
  `this` stays. Retail's copy moves the words at 0x50..0x5C with `lwc1`/`swc1`;
  MWCC emits the same instructions for the pointer-typed `image` member, so it
  is not typed `float` (`.private/fixes-r3c/drawprim-neg-image.log`,
  `drawprim-final.log`).
