# character natural access (2026-10-08 night)

Byte-identical object (`check_objects character`: 0x6BE4 bytes, 906 relocations).

## Replaced
- `CCharacter2::Initialize`: the `u8 *raw = (u8 *) this` writes are `velocity` (0x80-0x8C, w 1.0),
  `move_accel` (0xA0), `entry_matrix` (0xB0, passed to `mgUnitMatrix`), `main_frame_info` (0x500)
  and `seq_step` (0x3AC); `*(int *) &alpha = 0x3F800000` is `alpha = 1.0f`; float zeros are
  stored as `$zero` either way. `entry_object[i].size` (float) likewise takes `0.0f`; the motion
  table clears use `sizeof`.
- Sequence end test: `*((s8 *) playing + sizeof(CHRINFO_SEQ))` is `playing[1].name[0]`.
- `(char *) seq_step`, `(char *) first`, `(char *) now_key`, `(char *) now_key_ptr` are the
  `name` members at offset 0 of `CHRINFO_SEQ` / `CHRINFO_KEY_SET`.
- Effect entry: `(char *) node->effect + 0x1BC` and `*(float *) ((u8 *) manager + 0x1DC)` are
  `CHARA_EFFECT_MANAGER::motion_name` and `start_ratio` (the local is a `CHARA_EFFECT_MANAGER *`).
- `_OBJECT_NAME`: the two `offset` walks over `entry_frame` / `entry_object` become indexed `for`
  loops; the second needs its own counter `j` (reusing `i` swaps counter and offset in that loop,
  reusing `n` changes the later argument loop).
- `_OBJECT_NAME2`: the never-read `offset` counter is removed.
- `_MOTION` / `_SHADOW_MOTION`: `nowChr + id * 0x14 + 0x3C0/0x460` are `&nowChr->motion[id]` and
  `&nowChr->shadow_motion[id]`; `*(tagFRAME_INF **) ((u8 *) motion + 0x10)` is `motion->frame_info`.
- `CreateChangeFrame`: the byte `offset` over `mgCreateVisualType` entries becomes `&list[i]`
  (a pointer walk `entry++` is 12 bytes shorter), ending at `MG_VISUAL_CREATE_END`.
- `AddOutLine`, `_SHADOW_MOTION`: `*(s8 *) name` tests become `name[0]`.
- `DeleteExtMotion`, `DeleteImage`: `*(u8 *) image->name != '#'` becomes the value conversion
  `(u8) image->name[0]`; plain `image->name[0]` loads with `lb` instead of retail's `lbu`.
- `_MOTION`: the shadow motion entry of the new slot takes the first entry's
  `base_matrices`, `motion_list`, `skin_list` and `unk_0C` through
  `tagMOTION_TYPE *` locals instead of four `int` words.
- `CCharacter2::GetSoundInfoCopy`, `_CLOTH_START` and `_LOD_MODEL_START`:
  the stack block is held as the `u_long128 *` that `Alloc` returns and passed
  to the placement `new` without a `void *` round trip.
- `CCharacter2::CopyOutLine`: the shared screen texture is held in `mgCTexture *texture`
  instead of an `int enabled` cast back to `mgCTexture *` for each outline.
- Shadow scale: `nowChr->shadow_frame` is already `mgCFrame *`; the same-type cast on
  `SetScale` is dropped.
- `CCharacter2::main_frame_info` is `tagFRAME_INF *` (character.hpp), like
  `shadow_frame_info`; `Initialize` clears it with `NULL` (twice).
- `_SHADOW_MOTION`: `nowChr->shadow_frame` is passed without the same-type `(mgCFrame *)`.
- `CCharacter2::SePlay`: `se_list[now_set]` is already `CHRINFO_SE *`.
- Same-type casts dropped: `SetTag` arguments in `Initialize`/`DrawEffect` (already
  `SPI_TAG_PARAM *`), `GetPackFile` results in `_EFFECT_START`/`_LOD_MODEL` (already `u_int *`),
  `mgLoadMDSFile` in `CreateChangeFrame` (already `mgCFrame *`).
- `CCharacter2::GetSoundInfoCopy` and `_SE_START` allocate their `CHRINFO_SE` arrays with a
  placement `new (block) CHRINFO_SE[n]` instead of a cast `operator new[]` call.

## Kept
- `DeleteExtMotion`: `(mgIMG_FILE_HEADER **) ((u8 *) this + offset + 0x2C4)` with
  `offset += 4`. `&this->images[j]` and direct `this->images[j]` both swap `s4`/`s5` between the
  `images` local and the offset induction value.
- `(u8 *) img_ptr[i]` / `(char *) image` arguments to IMG-file APIs that take byte buffers, and
  `(mgCVisualMotionMDT *)` downcasts after `Iam()` checks, are ordinary conversions.
- `CCharacter2::Draw` LOD outline: the stack copy stays a local `OutlineCopy` POD viewed as
  `COutLineDraw`. A `COutLineDraw` local runs its constructor (`next = NULL; Initialize()`), which
  retail does not call.
- `CCharacter2::SetMotionPara`: `switch ((int) sequence)` with `case 0` stays;
  the equivalent `if (sequence != NULL)` changes the branch layout.
- `_SHADOW_MODEL`: `(s32 *) operator new[](bytes, ...)` for the frame link tables. `new (...)
  s32[count]` recomputes `count * 4` into a new register instead of reusing `bytes`.
- `_OUTLINE` and `CCharacter2::Copy`: `(COutLineDraw *) operator new(...)` followed by the
  constructor's `next = NULL; Initialize();`. `new (...) COutLineDraw` in `Copy` tests the copied
  register after the `move` and swaps `s4`/`s5`; in `_OUTLINE` it also renumbers the function's
  static locals in `.sbss`.
- Loaded data at API boundaries: `_SKIN_MOTION` hands its pack entries to `mgLoadData` as
  `MDS_HEADER *`, `unsigned int *` and `float (*)[4][4]` and the image copy to
  `mgGetIMGHeaderNum`/`mgGetIMGHeader` as `char *` (mangled parameter types);
  `DeleteExtMotion` steps from an `mgIMG_FILE_HEADER` to the `mgIMG_HEADER` records after it;
  `_KEY_START` starts the key list at the free top of `now_stack`.

## Entry-slot bounds (2026-10-09)

`_OBJECT_NAME` and `_OBJECT_NAME2` bound their free-slot searches by
`CHARA_ENTRY_FRAME_MAX` (2) and `CHARA_ENTRY_OBJECT_MAX` (0x18), the sizes of
`entry_frame` and `entry_object`, instead of literal `2`/`0x18`. The object is
unchanged (`.private/fixes-r3c/b1-*.log`).
