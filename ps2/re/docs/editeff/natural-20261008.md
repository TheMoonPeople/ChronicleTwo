# editeff natural access (2026-10-08 night)

Byte-identical object (`check_objects editeff`: 0x1C74 bytes, 265 relocations).

## Replaced
- `EditSetEffectBuffer`, `EditPlaceEffect`: the `offset += sizeof(CStarEffect)` byte walks over
  `_StarEffect` become `_StarEffect[i]`. Both match only with the element indexed at each use;
  a `CStarEffect *` element local (`star`, `candidate`) is coloured before the offset induction
  value and swaps their registers.
- `CStarEffect::ParamInit`: the `volatile u_long128` read of the local position
  is a plain quadword copy into `particle[i].position`.
- `EditSetEffectBuffer`: each star effect's particles are `new (...) EditStarParticle[*count]`
  instead of a cast `operator new[](*count << 5, ...)` call.

## Kept
- `*(u_long128 *)` vector copies: accepted quadword-copy convention.
