# mglib natural access (2026-10-08 night)

Guarded drafts untouched.

## Replaced
- `mgWaitFrame`, `mgDrawDirect(mgCVisual *, ...)` and `mgDrawDirect2`: the packet cursor is
  `mgVif1Packet->pCurrent` (the first member of `sceVif1Packet`) instead of
  `*(int *) mgVif1Packet`; `mgDrawDirect2` passes `pCurrent + ddraw_size * 4` instead of adding a
  byte offset to the integer.
- `mgEndDraw`: `EndDraw` takes `mgVif1Packet` (already a `sceVif1Packet *`) without a same-type cast.

## Kept
- `*(u_long *) &reg` GS register views (TEX1, TEST, ALPHA, TEXA, display buffers, packet A+D
  arguments) and `*(u_long128 *) &mgGiftagAD` SDK quadword arguments: accepted conventions.
- `*(volatile u_int *) timer0_count`, `*(volatile u_long *) gs_pmode` and the other
  `static const u_int` hardware addresses: memory-mapped register access, not object puns.
- `mgFlushRenderInfo`: `words[n] = *(u_int *) &mgRenderInfo.fog.x` writes the fog floats into
  VIF packet words through the integer pipe, as a packet word view.
- `CheckVuProgID` (`global_optimizer off`): `*(int *) ((id << 2) + (int) user_prog_adr -
  user_vu_prog_base * 4)`. `user_prog_adr[id - user_vu_prog_base]` subtracts before scaling and
  `(&user_prog_adr[id])[-user_vu_prog_base]` shortens the function; neither matches.
- `mgGetFogParam`: `*(mgFogColor *) &param->r = *(mgFogColor *) &mgRenderInfo.fog.r` copies the
  four colour bytes as one word; separate byte assignments would load and store each byte.
