# mglib hygiene pass (2026-10-09)

Scope: `mgEndFrame__FP14mgCDrawManager`, `mgSetPkFrameBuffer__Fiiii`. Checked
with a PAL build (`SCES_511.90: OK`) and `check_objects.py` (149/149).

## Changed
- `mgEndFrame`: the performance meter uses `ZMask(MG_Z_MASK_MASKED)` and
  `Begin(MG_PRIM_SPRITE)` (same values as `-1` and `SCE_GS_PRIM_SPRITE`; the
  repo's `Begin` callers use `MG_PRIM_*`).
- `mgEndFrame`: the three `(u_int)` casts on `timer0_count - h_count` /
  `- wait_start` are dropped. The left operand is a `volatile u_int` read and
  `h_count`/`wait_start` are `int`, so the difference is already `u_int`.
- `mgSetPkFrameBuffer`: the frame texture's TEX1 is
  `SCE_GS_SET_TEX1(1, 0, 1, 1, 1, 0, 0)` (= 0x261), as matched
  `mg_texture.cpp` writes the same register. The whole-register lvalue stays.

## Left as is
- PMODE/SMODE2/DISPFB/DISPLAY values: libgraph.h has no SET macros for them
  and the operand trees are what match.
- `262`, `60`, `sceDevConsAttribute(..., 7)`, `StoreImage(0)`: no owner.
- Outside this scope: `ZMask(-1)` / `Begin(6)` / `Begin(SCE_GS_PRIM_SPRITE)`
  in `mgBeginDrawShadow`/`mgEndDrawShadow`, and `mgInit`'s `mgTEX1_1 = 0x261`.
