# fishing: natural typed access (2026-10-08)

## Replaced

- `GetFishDist`: the rotation matrix local is `float matrix[4][4]` and is
  passed to `mgUnitMatrix` and `sceVu0RotMatrixY` without casts.
- The cast cursor position is passed as `CastPointCur.v` instead of
  `(float *) &CastPointCur`.
- `fpFISH_MAP_NUM`: the fish place map block is the `u_long128 *` that
  `Alloc` returns, passed to `operator new[]` without a cast.
- `CCameraControl`/`mgCCameraFollow` camera locals call the virtual `Iam()` directly; the
  `(mgCCamera *)` upcasts are no-ops.
- Player character: `chara` (`CCharacter2 *`) calls the inherited virtual `GetPosition` and
  `GetRotation` without the `(mgCObject *)` upcast (12 calls).
- `InitSelectCastingPoint`, `InitBattle`, `FalseLoop`, `SuccessLoop`: `camera` is a `CCameraControl *` assigned once from
  `(CCameraControl *) scene->GetCamera(...)` instead of an `mgCCamera *` downcast at each call;
  `Iam` and `Step` are virtual overrides, so the uncast calls dispatch the same.
- `sgSystemDrawFishing`: `GetTexture` already returns `mgCTexture *`.
- `fpFISH_PLACE`: `*name != 0` on the `char *` name instead of `*(signed char *) name`.
- `fpFISH_MAP_NUM`: `FishPlaceMap = new (block) FISH_PLACE_MAP[FishPlaceMapNum]` replaces the cast
  `operator new[]` call.
- `EndSelectCastingPoint`: the camera local is a `CCameraControl *`, so `CopyParam` takes `*camera`
  instead of dereferencing a cast `mgCCamera *`.

## Kept

- `*(u_long128 *) &CastPoint = *(u_long128 *) cast_dir` and the
  `CastPointCur` counterpart are quadword copies.
- `(u_char *) memory->Alloc(...)` converts fresh allocations to byte copies.
- `ThreadStack__2` stays an `int` address; it is aligned up to 64 bytes with `& 0x3F` before
  being handed to the thread as `void *`.
