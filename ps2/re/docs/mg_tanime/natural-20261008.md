# mg_tanime: natural typed access (2026-10-08)

## Kept

- `mgCTextureAnime::NewTexAnimeGroupData`: the head slot is
  `(CList<mgCTexAnimeData> **) ((group << 2) + (int) this + 0x64)`, which is
  `&list[group]`. Retail adds the scaled group to `this` with the index as
  the first operand (`addu v1,v0,s2`); `&list[group]` and `group + list` both put `this` first.
- Texture animation colour: `*(mgTexAnimeColor *) &entry->r = *(mgTexAnimeColor *) &data->r`
  copies the colour bytes as one record.
