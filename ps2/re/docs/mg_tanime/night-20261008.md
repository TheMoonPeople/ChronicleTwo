## Historical round-1 source and typework

This round predates the exact native rewrite in
[nmmisc-20261008.md](nmmisc-20261008.md). `TexAnime` is now native;

At this checkpoint `TexAnime` remained guarded. Its cleaned source differs
by **840/1304**
words, with a `0x13A0` body in retail's `0x1460` reservation. This is a
source-hygiene checkpoint, not a numerical improvement over the inherited
660-word draft, which still contained prohibited scaffolding.

Both group loops use the actual `enable`, `now`, `list` and `frame` arrays.
The drawing loop retains `&frame[group]` as its meaningful per-group
counter pointer; this brings the direct-index cleanup from 1151 to 840
words. Counter updates, wait comparisons and resets all use that pointer.
The current-record slot is `&now[group]`. Self-assignments, raw integer
views of the animator, redundant pointer copies and five zero-constructed
rectangles were removed in this historical draft. The palette rectangle
and the source rectangle passed to image copies remain real, used objects.

Retail performs six real `Set(0,0,0,0)` calls on distinct frame slots
`0x2C0` through `0x310`. Only the rectangle at `0x300` is subsequently
read. The empty `mgRect<int>` default constructor cannot express those
calls, so the matching rewrite uses explicit `(0,0,0,0)` construction of
six real rectangle locals. These calls are retail behavior; the five
unread rectangles are not artificial padding. The earlier 840-word draft
omitted them and is superseded by that reconstruction.

`clut_copy`, `bilinear` and `alpha_blend` are signed bytes. Retail `lb`
instructions read the fields at `TexAnime +0x34C`, `+0x25C` and
`+0x290/+0x2B0`, respectively; `EnterTexAnime` also copies them with signed
byte loads. Their declarations now express those loads directly, removing
the three pointer-punned copies and the draft's sign-conversion casts.
The record remains `0x34` bytes and its list node remains `0x40` bytes.
The full active consumer audit passes 149/149 objects, preserves all 149
object file hashes, and prints `SCES_511.90: OK`.
